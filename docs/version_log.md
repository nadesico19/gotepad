# 0.1.11

- 增加检测软件更新的功能。
- 优化UI细节。

# 0.1.10

- 【紧急】修复倒扑棋型无法正常提子的严重Bug。
- 分析模式可以设置额外数目的盘上候选标记。
- 分析模式中，当棋盘上锁不允许落子时，可通过点击盘上的候选标记直接进入变化图。
- 笔记面板追加专注模式，可以浏览和编辑所有笔记，浏览顺序与导出的PPT一致。
- 安卓版调整性能配置参数，可能优化功耗发热。
- 修复UI Bugs，优化UI细节。

# 0.1.9

- 新建棋盘界面增加“粘贴”入口，可以从系统剪贴板读取完整的 SGF 文本并创建棋谱。

# 0.1.8

- 优化UI细节。

# 0.1.7
