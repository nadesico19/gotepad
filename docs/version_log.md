# 0.1.7

- 增加从图片或者拍照新建棋盘的功能，拍照仅支持安卓版。
- 增加终局数目功能，仅支持中国规则。
- 增加将本软件注册为 SGF 文件打开方式的功能。
- 在打开持续分析时，进入和退出变化图、分支预览模式，不会关闭持续分析。
- 增加限制棋盘横向屏幕占比功能，用于一些特殊屏幕比例的移动端设备。
- 盘面最后一手数字使用强调色。
- 优化UI细节。

# 0.1.6

- 安卓版增加大UI模式，优化手机使用体验。
- 安卓版更新内置的10b权重，并开放外置权重加载功能。
- 提升SGF读写的健壮性。
- 在分析模式下，对胜率掉10点以上的下一手标红提示。
