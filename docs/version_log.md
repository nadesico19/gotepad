# 0.1.6

- 安卓版增加大UI模式，优化手机使用体验。
- 安卓版更新内置的10b权重，并开放外置权重加载功能。
- 提升SGF读写的健壮性。
- 在分析模式下，对胜率掉10点以上的下一手标红提示。
- 优化UI细节。

- 在中文基础上，追加适配日本语、韩国语、英语。
- 适配安卓平台，推荐使用安卓平板。
- 安卓版应用内嵌 katago 引擎，自动选择OpenCL/Eigen 后端。目前处于试验阶段，权重仅支持b10c128。
- 优化UI细节。
