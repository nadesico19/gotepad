# Gotepad 사용자 매뉴얼

[简体中文](user_manual.md) | [English](user_manual.en.md) | [日本語](user_manual.ja.md) | [한국어](user_manual.ko.md)

본 매뉴얼은 Gotepad 0.1.21에 적용됩니다. Gotepad는 바둑기보 작성, 대국 검토, 지사 조직, 국면 노트 및 PPTX 코스웨어 내보내기를 위한 크로스 플랫폼 클라이언트입니다. 프로그램은 아직 개발 단계에 있으므로 대규모 기보 수정을 하기 전에 백업을 저장하는 것이 좋습니다.

## 시작하기

Gotepad를 시작한 후 빈 바둑판을 생성하거나 SGF 기보을 파일 또는 시스템 클립보드에서 로드할 수 있습니다.

### 빈 바둑판 만들기

1. 오른쪽 상단의 '새로 만들기'를 클릭하거나 'Ctrl+N'을 누르세요.
2. 9, 11, 13, 15 또는 19 바둑판 라인을 선택합니다.
3. 생성을 클릭합니다.

직접 생성된 태그에는 기본적으로 "새 노트"라는 이름이 지정됩니다. 동일한 이름을 가진 태그가 있으면 프로그램은 이름 뒤에 숫자를 추가합니다.

### 이미지에서 바둑판 만들기

데스크톱 버전에서는 새 인터페이스에서 바둑판 크기를 선택하고 "로컬 사진 선택"을 클릭할 수 있습니다. Android 버전의 경우 "사진" 또는 "앨범"을 선택할 수 있습니다. iOS 버전에서는 “촬영”을 누르거나 오른쪽의 “이미지” 버튼으로 사진 보관함 또는 파일에서 이미지를 선택할 수 있습니다. 프로그램은 실제 사진, 인터넷 스크린샷 또는 책 사진에서 현재 바둑판를 식별하고 먼저 인식 및 교정 인터페이스를 표시할 수 있습니다. 세로 사진의 경우 먼저 "이미지를 시계 방향으로 회전"을 사용하여 표시 영역을 확장할 수 있습니다. 4개의 노란색 제어점을 드래그하여 바둑판의 가장 바깥쪽 4개 교차점에 정렬한 다음 "현재 4개 모서리에 따라 재식별"을 클릭합니다. 빈 지점, 검은 돌, 흰 돌 사이를 주기적으로 수정하려면 교차점을 클릭하세요. 중앙의 빨간 점은 프로그램 신뢰도가 낮은 위치를 나타내며 집중 점검을 권장합니다. 돌 마크는 아래의 실제 돌를 쉽게 확인할 수 있도록 원본 이미지의 가장자리 일부를 남겨둡니다. 확인 후 식별된 돌는 사전 배치 돌 노드로 생성되고 바둑판은 기본적으로 잠깁니다.

이미지 인식 결과는 촬영 각도, 반사, 돌 질감 및 화면 자르기에 영향을 받습니다. 생성하기 전에 네 모서리, 바둑판 크기 및 모든 빨간색 상자 위치를 확인해야 합니다. 디스크가 기본 바둑 규칙을 준수하지 않으면 프로그램은 생성을 거부하고 수정이 필요합니다.

### SGF 로드

새 인터페이스를 연 후 "로드"를 클릭하고 로컬 `.sgf` 파일을 선택할 수 있습니다. 먼저 다른 응용 프로그램에서 전체 SGF 텍스트를 복사한 다음 "붙여넣기"를 클릭하여 기보을 직접 만들 수도 있습니다. 클립보드를 통해 생성된 기보에는 연결된 소스 파일이 없으며 처음 저장할 때 선택해야 합니다.

성공적으로 로드된 후 바둑판은 첫 번째 분기의 마지막 국면으로 로밍되며 기보을 검색할 때 실수로 착수 또는 무르기를 방지하기 위해 기본적으로 잠겨 있습니다. 동일한 SGF 파일이 현재 열려 있는 경우 프로그램은 태그를 다시 생성하지 않지만 기존 태그를 활성화합니다. iOS에서도 시스템 파일 선택기에서 같은 원본 파일을 다시 열면 기존 탭으로 전환하고 그 탭의 저장되지 않은 변경 사항을 유지합니다. “다른 이름으로 저장” 후에는 새 저장 위치를 기준으로 파일을 식별합니다.

Windows 버전은 시작 매개변수로 `.sgf` 파일 경로를 받을 수 있습니다. 파일 탐색기에서 SGF를 여는 앱으로 Gotepad를 선택하거나 명령줄에서 SGF 경로를 `Gotepad.exe`에 전달하면 시작 후 기보를 바로 불러옵니다. 여러 SGF를 한 번에 전달하면 각각 별도의 탭으로 열립니다. Gotepad가 이미 실행 중인 상태에서 다른 SGF를 두 번 클릭하거나 SGF 경로와 함께 `Gotepad.exe`를 호출하면 파일이 처음 실행된 창으로 전달됩니다. 같은 파일이 이미 열려 있으면 기존 탭으로 전환합니다. SGF 경로 없이 `Gotepad.exe`를 직접 실행하면 독립된 새 창이 유지되므로 기보를 나란히 비교할 수 있습니다.

macOS 버전에서는 Finder에서 `.sgf` 파일을 마우스 오른쪽 버튼으로 클릭한 뒤 “다음으로 열기”에서 Gotepad를 선택하여 기보를 바로 불러올 수 있습니다. SGF를 Gotepad 앱 아이콘으로 드래그해도 됩니다. 여러 SGF를 한 번에 열면 각각 별도의 탭으로 불러옵니다. Gotepad가 이미 실행 중이면 시스템을 통해 연 기보는 처음 실행된 창으로 전달되어 탭으로 열립니다. 같은 파일이 이미 열려 있으면 기존 탭으로 전환하고 저장되지 않은 변경 사항을 유지합니다. 기보를 나란히 비교할 독립된 창을 하나 더 열려면 macOS의 “터미널”에서 SGF 경로를 추가하지 않고 `open -n "/Applications/Gotepad.app"`을 실행하세요. Gotepad가 “응용 프로그램” 폴더에 없다면 명령의 경로를 실제 App 경로로 바꾸세요. Finder에서 같은 Gotepad App을 다시 두 번 클릭하면 보통 기존 창만 활성화됩니다. `open -n`을 사용하면 새로운 독립된 창이 열립니다. Gotepad를 SGF의 기본 앱으로 설정하려면 파일의 “정보 가져오기”에서 Gotepad를 선택하고 “모두 변경”을 클릭하세요.

바둑판 태그가 있는 경우 새 인터페이스의 오른쪽 상단에 있는 `✕`를 클릭하거나 `Esc`를 눌러 닫고 현재 대국로 돌아갈 수 있습니다. 현재 바둑판이 없으면 닫기 버튼이 표시되지 않으며 바둑판을 생성하거나 로드해야 합니다.

## 화면 구성

- 상단에는 기보 탭바가 있습니다. 기보로 전환하려면 라벨을 클릭하고, 닫으려면 라벨에서 `✕`를 클릭하세요. 마지막 탭을 닫으면 새 노트가 자동으로 생성됩니다.
- 왼쪽에는 바둑판 및 대국 재생 막대가 있습니다.
- 메시지 및 확인 대화 상자는 현재 창 너비에 따라 자동으로 줄바꿈되며, 작업 버튼이 화면 밖으로 확장되는 것을 방지하기 위해 너비는 창의 2/3를 초과하지 않습니다.
- 인터페이스에는 “헤이즐우드와 크림” 색상 조합을 사용합니다. 짙은 커피색 패널에 크림색 글자를 배치하고, 사용 가능한 버튼에는 밝고 따뜻한 황금빛 갈색 테두리를 사용합니다. 비활성화된 버튼에는 짙은 갈색 배경과 테두리, 회갈색 글자나 아이콘을 사용합니다. 주요 작업이나 선택 상태는 캐러멜 골드로, 삭제나 지우기처럼 신중한 확인이 필요한 작업의 버튼은 짙은 빨간색으로 표시합니다. 바둑판 잠금 등의 체크박스는 짙은 갈색 바탕과 밝은 크림색 윤곽선을 사용하며, 선택하면 상자 안에 체크 표시가 나타나 나뭇결 배경에서도 쉽게 구분할 수 있습니다. 메시지 및 확인 대화 상자의 버튼은 마우스를 올리거나 누를 때, 키보드 포커스를 받을 때 시각적 피드백을 제공합니다. 색상뿐 아니라 버튼의 글자로도 작업 내용을 확인할 수 있습니다. 바둑판과 배경은 기존 모습을 유지하며, 시스템 파일 선택기는 기기 자체의 스타일을 사용합니다.
- 바둑판의 오른쪽에는 창 높이에 따라 자동으로 열을 변경하는 조작 버튼이 있습니다.
- 오른쪽 상단에는 톱니바퀴 모양의 설정 버튼과 새로 만들기, 저장, 다른 이름으로 저장, 내보내기, 도구, 매뉴얼, 업데이트가 배치됩니다. 도구 메뉴에는 사용 빈도가 낮은 기보 처리 기능이 모여 있습니다. “매뉴얼”를 누르면 설정에서 선택한 인터페이스 언어의 GitHub 사용자 매뉴얼가 브라우저에서 열립니다. 인터넷 연결이 필요합니다.
- 참고사항, 기보 정보와 KataGo는 동일한 측면 패널 영역을 사용하며, 그 중 하나를 열면 다른 패널이 축소됩니다.

인터페이스는 창의 실제 높이에 따라 자동으로 조절됩니다. 기본 배율은 900픽셀 이하에서 1.0배이며, 900~2000픽셀 사이에서 선형으로 증가하고 2000픽셀 이상에서 2.0배가 됩니다. 설정의 “UI 배율”을 켜면 기본 배율에 선택한 배율을 곱합니다. 글꼴, 버튼, 아이콘, 패널, 대화상자도 함께 확대되며, 바둑판 카메라는 사용할 수 있는 공간을 다시 계산하여 바둑판 전체를 표시합니다.

데스크톱 버전은 `user://window_state.cfg`에 있는 일반 창의 위치, 크기 및 최대화된 상태를 기억하고 다음에 시작할 때 이를 복원합니다. 모니터를 변경하거나 데스크탑 레이아웃을 변경한 후 저장된 위치가 더 이상 화면의 사용 가능한 영역에 속하지 않는 경우 창이 자동으로 홈 화면 중앙으로 돌아갑니다. 모바일 버전과 웹 버전은 이 창 상태를 사용하지 않습니다.

## 바둑판 조작

### 착수

- 바둑판 잠겨 있지 않은 경우 법적 교차점에서 마우스 왼쪽 버튼을 클릭하면 됩니다.
- 사용 가능한 위치 위에 마우스를 올리면 반투명 미리보기가 표시됩니다.
- 흑백 돌 전환 버튼이나 `Ctrl+Q`를 사용하여 다음 색상을 지정합니다. 일반 착수 이후에는 기본적으로 흑백 교대가 복원됩니다.

"착수 확인"을 활성화하면 합법적인 교차점을 처음 클릭했을 때 반투명한 대기 중인 돌만 표시되며 기보는 즉시 변경되지 않습니다. 설정 오른쪽에서 확인 방식을 "아이콘으로 확인" 또는 "다시 클릭"으로 선택할 수 있습니다. "아이콘으로 확인"은 바둑판 오른쪽 도구 모음 상단에 녹색 `✓`와 빨간색 `✕`를 임시로 표시하며, 각각 착수 확인과 취소에 사용합니다. "다시 클릭"은 이 두 임시 버튼을 표시하지 않으며 현재 반투명 돌이 놓인 교차점을 다시 클릭해야만 착수가 확정됩니다. 어느 방식을 사용하든 확정 전에 다른 합법적인 교차점을 클릭하면 대기 중인 돌이 이동합니다. 바둑판 밖의 빈 배경을 클릭하거나 마우스 오른쪽 버튼을 클릭하면 취소할 수 있습니다. 인간 모방 대국에서 대기 중인 착수를 취소하면 저장 후 종료하는 녹색 `✓`를 다시 사용할 수 있습니다. 기존 다음 수 분기로 들어갈 때는 이전과 마찬가지로 확인 없이 바로 이동합니다. 이 기능은 데스크톱 버전에서는 기본적으로 꺼져 있고 Android와 iOS 등의 모바일 버전에서는 기본적으로 켜져 있습니다. 사용자가 저장한 설정은 플랫폼 기본값보다 우선합니다.
- 본 프로그램은 기본수칙을 준수하며, 자살 등 불법행위를 용인하지 않습니다.

바둑판은 반투명 그래픽으로 입력할 수 있는 모든 다음 착수 분기를 표시합니다. 현재 재생 경로의 다음 손은 사각형을 사용하고 다른 분기는 원을 사용합니다. 마커를 클릭할 때:

- 현재 선택된 색상이 기존 브랜치 착수과 동일할 경우 해당 브랜치가 입력됩니다.
- 현재 선택한 색상이 기존 브랜치 착수과 반대인 경우 동일한 위치에 선택한 색상의 새 브랜치가 생성됩니다.
- 잠금 상태에서도 사각형 또는 원형 분기 표시를 눌러 해당 분기로 이동할 수 있으며 새 수를 만들지 않습니다. KataGo 후보 표시와 분기 표시가 겹치면 후보 변화도로 들어가는 동작이 우선합니다.

### 무르기, 실행 취소 및 다시 실행

- 잠금 해제 상태에서 마우스 오른쪽 버튼을 누르면 무르기 확인을 요청합니다. 확인하면 현재 착수 또는 사전 배치 노드와 그 이후의 모든 분기를 삭제하고 이전 국면으로 돌아갑니다. 기보 중간에서 무르면 후속 기록도 삭제되므로, 이전 국면을 보기만 하려면 재생 조작을 사용하거나 먼저 바둑판을 잠그세요.
- 바둑판이 잠겨 있는 경우 기보을 수정하지 않고 마우스 오른쪽 버튼을 누르면 이전 국면으로 로밍되도록 변경됩니다.
- 무르기는 기보 편집 명령이며 실행 취소와 동일하지 않습니다.
- `Ctrl+Z`는 최근의 취소 가능한 명령을 실행 취소하고 `Ctrl+R`은 다시 실행합니다. 무르기로 삭제한 노드와 후속 분기도 실행 취소로 복원할 수 있습니다. 바둑판 잠금은 기보 편집을 포함한 실행 취소 및 다시 실행을 막지 않습니다.
- 아이콘에 슬래시가 있으면 해당 실행 취소 또는 다시 실행을 현재 실행할 수 없다는 의미입니다.

### 바둑판 잠금

바둑판 잠금을 확인하거나 `Ctrl+E`를 누르면 착수 및 무르기는 금지되지만 여전히 허용됩니다.

- 재생 막대, 마우스 휠 및 화살표 키를 사용하여 대국을 탐색합니다.
- 다음 분기 표시를 클릭합니다.
- 돌 찾기 및 직접 착수이 아닌 분기 검색과 같은 기능을 사용합니다.
- 기보 편집을 포함한 실행 취소 및 다시 실행.

잠금 바둑판은 SGF를 로드한 후 기본적으로 활성화됩니다.

## 재생 및 기보 탐색

바둑판 아래의 재생 막대는 선형 대국 경로의 현재 위치를 나타냅니다.

재생 막대 왼쪽의 “배치” 버튼과 오른쪽의 뒤로, 앞으로, 재생 버튼은 비활성화되면 글자나 아이콘의 불투명도를 낮춰 표시하며, 비활성 배경은 표시하지 않습니다.

- 재생 막대를 드래그하거나 클릭하면 점프할 수 있습니다.
- 재생바에 마우스를 올리면 해당번호 수 번호이 표시됩니다.
- `<`, `>`를 클릭하면 한 손으로 앞이나 뒤로 탐색할 수 있습니다.
- 바둑판에 마우스를 놓으면 스크롤 휠이 위로 뒤로 이동하고 아래로 앞으로 이동합니다.
- 키보드 `←`, `→`는 전역 단일 단계 탐색 키입니다. 텍스트 상자나 목록을 편집하는 동안에는 키가 선점되지 않습니다.
- 재생 버튼을 클릭하면 설정된 간격에 따라 자동으로 진행됩니다. 중지 아이콘을 다시 클릭하거나 'Esc'를 눌러 중지하세요.
- 재생 중에 사용자가 재생 막대, 스크롤 휠, 방향 키 등을 사용하여 진행률을 변경하면 자동 재생이 중지됩니다.
- 모든 플랫폼에서는 앞으로 `>`, 뒤로 `<` 이동하는 큰 사각형 버튼 두 개도 화면 오른쪽 아래에 표시되며 위에서부터 앞으로, 뒤로 순서입니다. 일반 기보 모드에서는 기보를 한 수씩 이동하고 노트의 "집중" 모드에서는 노트 페이지를 전환합니다. 재생 막대의 기존 작은 버튼도 그대로 사용할 수 있습니다.

여러 분기가 있는 기보의 경우 재생 막대는 현재 선택된 선형 경로만 나타내며 이는 전체 기보 트리와 동일하지 않습니다.

## 분기 조작

### 본선만 유지

오른쪽 상단의 “도구”에서 “본선만 유지”를 선택하면 기보 시작부터 각 단계의 첫 분기를 따라 마지막 끝 노드까지 이어지는 경로만 남기고 모든 곁가지를 삭제합니다. 실행 전에 확인을 요청하며, 실행 후에는 남긴 본선의 마지막 국면으로 이동합니다. 전체 작업이 하나의 명령으로 기록되므로 한 번의 실행 취소로 삭제된 모든 분기와 작업 전 국면을 복원할 수 있습니다.

### 돌 찾기

![돌 찾기 방향으로 대국 시작 방향](../gotepad-gd/assets/ui/find_previous.svg)

![대국 방향 끝 방향 돌 찾기](../gotepad-gd/assets/ui/find_next.svg)

1. 앞으로 또는 뒤로 돌 찾기 아이콘을 클릭하거나 'Ctrl+G' 또는 'Ctrl+F'를 각각 누르십시오.
2. 불투명 돋보기 위치를 확인하기 위해 마우스를 대상 교차점 또는 돌로 이동합니다.
3. 왼쪽 버튼을 누르면 지정한 방향에서 해당 교차점의 착수 기록을 찾아 그 수로 이동합니다.

시작 방향 검색에는 현재 수가 포함됩니다. 끝 방향 검색은 현재 재생 경로를 따라가며 다른 곁가지를 검색하지 않습니다. 검색 대상은 착수 위치이며, 돌을 따내어 빈 점이 된 변화나 사전 배치 수정은 검색 결과에 포함되지 않습니다. 찾지 못하면 찾기 모드를 종료하고 안내를 표시합니다. `Esc` 또는 마우스 오른쪽 버튼으로 취소할 수 있습니다.

### 다음 분기 조정 또는 삭제

![브랜치 재정렬](../gotepad-gd/assets/ui/reorder_branch.svg)

이 버튼은 현재 국면에 하나 이상의 하위 분기가 있는 경우 사용할 수 있으며 'Ctrl+X'를 눌러 열 수도 있습니다. 착수 분기와 사전 배치 돌 분기가 모두 나열됩니다.

- 각 줄의 양쪽에 있는 `↑`와 `↓`를 사용하여 순서를 조정하고, 패널 상단의 녹색 `✓`을 클릭하여 결과를 작성합니다.
- 해당 브랜치의 바둑판 썸네일을 더블클릭하거나, 썸네일 오른쪽의 'Enter' 버튼을 클릭하면 해당 브랜치로 직접 로밍할 수 있습니다. 그러면 패널에 새로운 국면의 다음 분기가 표시됩니다. 진입 전에 확인되지 않은 순서 조정은 포기됩니다.
- 줄 끝의 빨간색 `✕`을 클릭하여 분기와 모든 후속 노드를 확인하고 삭제합니다.
- 패널 상단의 빨간색 `✕`을 클릭하거나 `Esc`를 눌러 커밋되지 않은 시퀀스 조정을 취소합니다.

확인된 분기 삭제는 즉시 수행되며 실행 취소를 통해 되돌릴 수 있습니다. 이후에 재정렬이 취소되는지 여부는 영향을 받지 않습니다. Undo를 통해 복원된 분기는 분기 순서의 끝으로 돌아가며 자동으로 원래 위치로 돌아가지 않습니다.

### 사전 배치 돌 분기

![사전 배치 돌 분기](../gotepad-gd/assets/ui/setup_branch.svg)

다음 단계에서 단일 착수 상자로 표현할 수 없는 사전 배치 돌개의 분기가 있는 경우 도구 모음 상단에 수량 프롬프트가 있는 버튼이 나타납니다. 클릭 후 각 브랜치로 인한 바둑판 변경 사항을 확인하고 대상 브랜치 입력을 선택할 수 있습니다.

### 분기 시각화

![분기 시각화](../gotepad-gd/assets/ui/branch_visualization.svg)

아이콘을 클릭하거나 'Ctrl+W'를 눌러 기보 트리 보기를 엽니다. 뷰에는 분기 키 노드, 메모가 있는 노드, 각 분기의 리프 노드가 포함됩니다. 큰 기보이 처음으로 생성되면 진행 상황이 표시됩니다. 생성된 썸네일은 기보 및 UID에 의해 캐시됩니다.

- 휠을 스크롤하여 보기를 확대/축소합니다.
- 데스크톱 버전에서는 마우스 오른쪽 버튼을 누른 채 캔버스를 드래그할 수 있습니다. 바둑판 썸네일이나 버튼에 닿지 않는 빈 영역에서 마우스 왼쪽 버튼으로 드래그할 수도 있어 오른쪽 드래그를 지원하지 않는 터치패드에서도 화면을 이동할 수 있습니다.
- 터치 입력을 지원하는 기기에서는 바둑판 썸네일이나 버튼에 닿지 않는 빈 영역에서 한 손가락으로 드래그하여 화면을 이동할 수 있습니다. Android와 iOS 터치 기기는 두 손가락을 모으거나 벌려 확대·축소하고 두 손가락으로 드래그하여 화면을 이동하는 기능도 지원합니다. 확대·축소는 두 손가락 사이의 중점을 중심으로 이루어집니다.
- 국면을 선택하려면 썸네일을 마우스 왼쪽 버튼으로 클릭하세요.
- 확인란 왼쪽 상단에 있는 녹색 `✓`을 클릭하거나, 선택한 썸네일을 두 번 클릭하여 국면으로 이동하고 보기를 종료합니다.
- 체크박스 오른쪽 상단의 빨간색 `✕`을 클릭하고 국면 및 모든 후속 브랜치 삭제를 확인합니다.
- 오른쪽 상단에 있는 "종료"를 클릭하거나 'Esc'를 눌러 보기를 닫습니다.

첫 번째 수준 노트의 제목은 썸네일 위에 표시됩니다. 댓글이 있는 경우 제목 뒤 댓글의 첫 번째 줄을 연결하는 데 세미콜론이 사용됩니다. 제목이 비어 있으면 댓글의 첫 번째 줄만 표시됩니다. 댓글 앞에는 노트북 마커가 표시됩니다. 제목은 최대 2줄까지 표시할 수 있습니다. 한 줄이면 바둑판에 가까울 것입니다. 내용이 너무 길면 바둑판 너비로 잘립니다.

## 사전 배치 돌

재생 바 왼쪽에 있는 "사전 설정"을 클릭하거나 'Ctrl+H'를 눌러 사전 설정 모드로 들어갑니다. 입장 후 흑백 색상 전환을 제외한 일반 버튼은 일시적으로 숨겨집니다.

- 교차점을 마우스 왼쪽 버튼으로 클릭하여 현재 색상을 사전 배치 돌으로 설정합니다.
- 마우스 오른쪽 버튼으로 교차점의 돌을 지우거나, 오른쪽 지우개 버튼을 선택한 뒤 지울 교차점을 누릅니다.
- 사전 배치 모드에는 흑돌, 백돌, 지우개가 있으며 누른 도구가 활성화됩니다. 활성화된 지우개는 금색으로 표시됩니다. `Ctrl+Q`로 흑백을 전환할 수도 있습니다. 사전 배치 후에는 색상이 자동으로 바뀌지 않습니다.
- 녹색 `✓`로 모든 변경을 한 번에 적용합니다. 착수 노드 또는 빈 바둑판의 시작점에서는 사전 배치 노드를 새로 만들고, 기존 사전 배치 노드에서는 새 노드 없이 해당 노드를 직접 수정합니다. 적용한 변경은 실행 취소로 되돌릴 수 있습니다.
- 이 수정 사항을 취소하려면 빨간색 '✕'을 클릭하거나 'Esc'를 누르세요.

최종 배치 국면은 모든 돌무리에 활로가 있는 등 기본 규칙을 만족해야 합니다. 기존 사전 배치 노드를 수정할 때는 새 국면에서 모든 후속 분기를 재생할 수 있는지 확인합니다. 충돌이 있으면 변경을 취소하고 처음 충돌한 노드의 UID를 표시합니다. 수정을 계속하려면 기보를 백업한 뒤 충돌하는 후속 분기를 먼저 정리하세요. 바둑판 잠금 상태에서는 사전 배치 모드에 들어갈 수 없습니다.

## 변화도

![변화도](../gotepad-gd/assets/ui/variation.svg)

변화도 아이콘 또는 `Ctrl+T`를 누르면 현재 바둑판을 변화도의 시작점으로 임시 기보에 복사하고 원래 규칙과 덤을 이어받습니다. 이전 수순은 복사하지 않으므로 시작 국면과 그 이후 변화만 탐색할 수 있습니다. 주 기보를 즉시 수정하지 않고 시험 착수를 할 수 있으며, 원래 바둑판이 잠겨 있어도 변화도에서는 둘 수 있습니다.

- 진입 시 원래 다음 수의 색상을 이어받고 이후에는 기본적으로 흑백이 교대로 둡니다.
- 재생 막대, `<`, `>`, 키보드의 `←`, `→` 또는 바둑판과 재생 막대 위의 마우스 휠로 기록된 변화를 탐색합니다. `←`는 뒤로, `→`는 앞으로 이동하며, 휠은 일반 모드와 같이 위로 돌리면 뒤로, 아래로 돌리면 앞으로 이동합니다. 입력란이나 목록에 포커스가 있으면 방향키는 해당 컨트롤을 조작합니다.
- 변화도에서는 자동 재생과 그 밖의 일반 바둑판 도구 및 단축키(`Ctrl+Q`, 실행 취소 및 다시 실행 포함)를 사용할 수 없습니다.
- 중간 국면에서도 둘 수 있습니다. 기록된 다음 수와 같은 위치에 두면 그 수로 바로 이동합니다. 다른 위치에 두면 추가 확인 대화상자 없이 현재 국면 이후의 기록을 모두 삭제하고 새 수를 둡니다. 착수 확인 기능이 켜져 있으면 중간에서 다른 수를 둘 때도 먼저 반투명 미확정 돌을 표시합니다. 선택한 방식으로 착수를 확인한 뒤에만 이후 기록을 대체하며, 미확정 착수를 취소하면 기존 기록이 유지됩니다.
- 마우스 오른쪽 버튼 또는 오른쪽 지우개 모양의 “무르기” 버튼을 누르면 추가 확인 대화상자 없이 바로 실행합니다. 끝에서는 마지막 한 수를 삭제하고, 중간에서는 현재 수와 이후의 모든 변화를 삭제한 뒤 이전 국면으로 돌아갑니다. 예를 들어 10수가 기록되어 있고 5수를 보고 있다면 5~10수를 삭제하고 4수로 돌아갑니다. 변화도의 시작점에서는 무를 수 없으며 원래 기보의 돌도 삭제하지 않습니다.
- 착수 확인 기능이 켜져 있으면 오른쪽 버튼은 먼저 미확정 반투명 돌을 취소합니다. 그 뒤 다시 오른쪽 버튼을 누르면 무르기를 실행합니다.
- 녹색 `✓`는 진입 시 원래 기보의 국면부터 변화도 전체를 주 기보에 저장하고 종료합니다. 중간 국면을 보고 있어도 그 이후의 기존 변화까지 함께 저장합니다. 기존 착수와 일치하면 기존 분기로 이동하고, 다르면 새 분기를 만듭니다.
- 빨간색 `✕` 또는 `Esc`는 모든 임시 변화를 버리고 진입 전 국면으로 돌아갑니다. 종료하면 원래 바둑판 잠금 상태가 복원됩니다. 버릴 때는 다음 수의 색상도 복원하며, 저장하면 주 기보는 저장한 수순의 끝에 머뭅니다.

KataGo 후보 변화도로 들어가면 후보 수순이 임시 기보에 자동 입력되며 패스 또는 기권에서 입력을 멈춥니다. 계속 두거나 중간에서 다른 수를 두거나 무를 수 있습니다. 저장하면 남아 있는 후보 수순과 직접 추가한 착수를 함께 저장합니다. 진입 전에 열려 있던 KataGo 분석 패널은 잠시 숨겨졌다가 종료 후 다시 열립니다.

## 국면 노트 및 바둑판 표시

![메모](../gotepad-gd/assets/ui/notes.svg)

메모 아이콘을 클릭하거나 'Ctrl+M'을 눌러 메모 패널을 엽니다. 동일한 국면에는 여러 개의 메모 레이어가 있을 수 있습니다.

- '+'를 클릭하면 0부터 시작하는 번호가 매겨진 메모 레이어를 추가할 수 있습니다.
- 중간 번호가 어긋나지 않도록 가장 높은 번호의 마지막 노트 층만 닫을 수 있습니다. 닫으면 해당 내용이 삭제되지만 실행 취소로 복원할 수 있습니다.
- 음 번호 0은 현재 착수 또는 사전 설정 노드에 저장됩니다. 후속 노트는 SGF의 독립 노드에 저장됩니다.

각 수준의 참고 사항에는 노드 제목, 설명, 바둑판 표시 및 수 번호 메서드가 포함됩니다. 제목이나 댓글이 변경되면 옆에 있는 녹색 `✓`을 사용하여 수락하거나 빨간색 `✕`을 사용하여 삭제합니다. 편집 중에 `Esc`를 누르면 편집이 취소되고 입력 포커스가 해제됩니다. 확인되지 않은 내용이 있는 다른 컨트롤을 클릭하면 프로그램에서 해당 컨트롤을 유지할지 여부를 묻습니다.

수 번호 옵션 오른쪽의 “집중”를 누르면 전체 기보의 노트를 미리 볼 수 있습니다. 페이지는 PPTX 내보내기와 같은 기보 트리 순서이며 같은 국면의 노트 층은 번호순으로 표시됩니다. 현재 국면에 노트가 있으면 선택한 층부터 시작하고, 없으면 뒤쪽의 가장 가까운 노트로 이동하며 뒤쪽에 없으면 앞쪽으로 이동합니다. 재생 막대로 노트 사이를 이동하고 `<`, `>`로 한 페이지씩 넘기며 재생 버튼으로 설정 간격에 맞춰 자동으로 넘길 수 있습니다. 오른쪽 하단의 큰 이동 버튼도 사용할 수 있습니다. 내용, 번호 방식, 표시는 편집할 수 있지만 `+`와 `✕`로 노트 층을 추가·삭제하거나 상단 탭으로 직접 전환할 수는 없습니다. 페이지 전환에는 재생 조작을 사용하세요. “집중”는 “나가기”로 바뀌며 누르면 일반 노트 모드로 돌아갑니다. 노트가 없는 기보는 미리 볼 수 없습니다.

모든 플랫폼에서 노트 제목과 댓글 편집 영역에 “전체 선택, 복사, 잘라내기, 붙여넣기” 터치 버튼을 제공합니다. 텍스트 입력란에 커서를 놓거나 일부 텍스트를 선택한 뒤 해당 버튼을 누르면 시스템 클립보드와 텍스트를 주고받을 수 있습니다. 데스크톱 버전에서는 시스템 단축키와 마우스 오른쪽 버튼 메뉴도 계속 사용할 수 있습니다.

착수 트리를 완성하고 노트를 작성하려면 오른쪽 상단의 “도구”에서 “노드 노트 생성”을 선택하세요. 먼저 기능 개요가 표시되며, “생성”을 누르면 실행하고 “취소”를 누르면 노트를 만들지 않고 돌아갑니다. 전체 기보를 순회하여 직속 분기가 두 개 이상인 노드와 후속 분기가 없는 말단 노드마다 노트 페이지를 하나씩 만듭니다. 새 페이지의 제목은 `TODO`이며, 댓글과 바둑판 표시는 비워 두고 수 번호에는 기본 방식을 사용합니다. 초기 빈 바둑판과 배치 노드에도 같은 조건을 적용합니다. 이미 노트 페이지가 있는 노드는 페이지가 비어 있어도 건너뛰므로 중복 생성되지 않습니다. 생성해도 현재 국면은 바뀌지 않습니다. 한 번의 실행 취소로 생성한 페이지 전체를 되돌리고, 다시 실행으로 복원할 수 있습니다.

전체 기보의 노트를 제거하려면 오른쪽 상단의 “도구”에서 “모든 노트 지우기”를 선택하세요. 확인 후 모든 국면의 제목, 댓글, 수 번호 방식과 바둑판 표시를 지웁니다. 전체 작업이 하나의 기록 단계로 처리되므로 한 번의 실행 취소로 완전히 복원할 수 있습니다.

### 바둑판 표시

`ABC` 문자 표시는 같은 위치에서 도형 표시와 함께 사용할 수 있습니다. 삼각형, 사각형, 원, 십자 등의 도형 표시끼리는 상호 배타적이므로 같은 위치에는 한 종류만 둘 수 있습니다. 다른 도형을 추가하면 기존 도형을 교체합니다.

- `ABC` : A-Z, a-z 순으로 문자 표시를 추가합니다.
- `TR`: 삼각형 표시.
- `SQ`: 상자 표시.
- `CR`: 원 표시.
- `MA`: 십자 표시.
- 지우개: 도형 표시를 지웁니다.

표시 모드에서는 다른 화면 요소가 잠시 숨겨지지만, 기보에 기록된 다음 착수 분기의 사각형·원형 위치 안내는 계속 표시되어 다음 착수 위치에 표시를 추가하기 쉽습니다. 노트 미리보기에서 표시 모드로 들어갈 때도 이 안내가 표시됩니다. 안내 위치를 누르면 분기로 이동하지 않고 노트 표시를 추가하거나 편집합니다. 빈 교차점이나 돌을 왼쪽 버튼으로 눌러 표시를 추가합니다. 문자 표시는 누른 순서대로 배정되며, 기존 문자를 다시 누르면 삭제되고 이후 문자가 다시 배정됩니다. 같은 교차점에는 도형 한 종류만 둘 수 있습니다. 다른 도형을 선택해 누르면 기존 도형을 교체하며 삭제할 때는 지우개를 사용합니다. 오른쪽 녹색 `✓`로 적용하고 빨간색 `✕` 또는 `Esc`로 버립니다. 흑돌 위에는 밝은 색, 백돌과 빈 점에는 어두운 색으로 표시합니다.

### 수 번호

번호 매기기 방법은 주로 PPTX 조판에 사용됩니다.

- **분기 상대 번호 매기기**: 이전 레이아웃 개체 노드 이후 1부터 번호를 다시 매깁니다.
- **분기 절대 번호 매기기**: 이전 레이아웃 개체 노드의 착수만 현재 국면으로 표시하지만 번호 매기기에서는 현재 분기의 해당 착수 중 실제 수 번호을 사용합니다.
- **Global Absolute Numbering**: 대국의 시작점부터 현재 경로의 모든 착수에 대해 실제 수 번호을 사용합니다.
- **번호 없음**: 내보낸 바둑판은 수 번호을 표시하지 않습니다.

동일한 교차점에 착수이 여러 개 있는 경우 내보내기에는 가장 작은 숫자가 먼저 표시되고 이 숫자와 바둑판 아래 후속 숫자 간의 대응 관계가 설명됩니다.

메모 패널이 열려 있고 현재 국면에 메모가 있는 경우 현재 메모 탭에서 선택한 번호 매기기 방법에 따라 바둑판이 표시되도록 우선순위가 부여되며, 설정 패널의 일반 수 번호 표시 옵션을 일시적으로 무시합니다. 메모 태그를 전환하거나 메모를 사용하여 다른 국면으로 로밍한 후 동시에 업데이트됩니다. 현재 국면에 메모가 없고 `+` 태그만 표시되면 일반 설정이 사용됩니다. 노트 패널을 닫은 후에도 일반 설정이 복원됩니다.

## 기보 정보

![기보정보](../gotepad-gd/assets/ui/sgf_info.svg)

기보 정보 패널에서는 대국 이름, 이벤트, 라운드, 날짜, 위치, 흑백 이름 및 단급, 결과, 규칙, 덤, 접바둑 돌 수 번호, 시간, 카운트다운, 레이아웃 이름, 레코더, 소스, 저작권 및 대국 일반 등급 및 기타 일반적으로 사용되는 SGF 헤더 정보를 편집할 수 있습니다. 규칙 제목 오른쪽 버튼으로 `Chinese`, `Japanese`, `Korean` 중 하나를, 덤 제목 오른쪽 버튼으로 `0`, `6.5`, `7.5` 중 하나를 한 번에 입력할 수 있습니다. 입력란에 직접 입력할 수도 있습니다. 제목 표시줄 오른쪽의 `∧`, `∨` 버튼을 사용하면 현재 보이는 높이의 3분의 2만큼 위아래로 부드럽게 스크롤할 수 있습니다.

수정 후 패널 상단의 녹색 `✓`을 클릭하면 모든 필드를 한꺼번에 제출할 수 있고, 빨간색 `✕`을 클릭하면 포기할 수 있습니다. 편집 내용이 초점을 잃으면 유지할지 여부도 묻습니다. 날짜, 덤, 접바둑 돌 수 번호, 시간 및 결과와 같은 필드는 인터페이스 예시 형식을 따라야 합니다. 그렇지 않으면 저장할 때 SGF 유효성 검사기에 의해 거부될 수 있습니다.

## SGF 저장 및 불러오기

- "저장"을 클릭하거나 `Ctrl+S`를 누르고 경로를 확인한 후 현재 기보을 저장합니다.
- "저장"을 클릭하거나 `Ctrl+A`를 눌러 새 파일을 선택합니다.
- 기존 위치에 저장할 때도 저장 확인을 요청합니다. SGF 저장 성공 창은 따로 표시하지 않습니다. 최초 저장 또는 다른 이름으로 저장에 성공하면 탭 이름이 저장한 파일 이름으로 바뀝니다. 실패하면 오류 창이 표시됩니다.
- 현재 태그를 닫으면 닫혔는지 여부만 확인되며 아직 완전한 '저장되지 않은 수정 사항' 상태 감지가 구현되지 않았습니다. 적극적으로 저축하는 습관을 길러주세요.

SGF 불러오기, 저장, 내보내기 또는 KataGo 파일 선택 중에는 파일 선택기를 하나만 열 수 있으며 같은 버튼을 반복해서 눌러도 두 번째 선택기는 열리지 않습니다. Windows에서는 Gotepad 뒤에 가려진 네이티브 파일 선택기를 다시 클릭하는 것만으로 항상 전면에 가져올 수 없으므로 작업 표시줄이나 `Alt+Tab`으로 이미 열린 선택기로 전환하십시오.

Gotepad는 경로 번호, 법적 파일, 지점, AB/AW/AE 사전 설정 작업, 제목, 설명, 공통 태그 및 기본 비밀번호 정보를 읽고 씁니다. 이 프로그램은 또한 형식 버전, 국면 UID 및 메모 번호 매기기 방법을 저장하는 데 사용되는 `AP[Gotepad:Version]`, `GP`, `XU` 및 `XN`과 같은 Gotepad 사용자 정의 속성을 작성합니다.

새 기보와 규칙 또는 덤 정보가 없는 불러온 기보에는 `Chinese` 규칙과 `7.5` 덤을 사용합니다. 불러올 때 KataGo가 규칙 이름을 인식하지 못하거나 덤이 0에서 100 사이의 0.5 단위 값이 아니면 경고를 표시하고 위 기본값으로 바꿉니다. 소수 부분이 0.25 또는 0.75인 덤에는 중국식 '子' 단위와 집 단위를 혼동했는지 확인하라는 별도 경고도 표시합니다. Gotepad가 보존할 수 있는 SGF 루트 확장 속성에서는 식별자에 포함된 규격 외 문자를 제거합니다. 수정 후 식별자가 비거나 기존 속성과 충돌하는 비정상 속성은 버리고, 불러오기가 끝난 뒤 경고를 표시합니다. 다시 저장하면 수정된 내용이 Gotepad 호환 형식으로 기록됩니다.

SGF를 저장할 때 Gotepad는 쓰기 실패 및 원본 파일 손상을 방지하기 위해 보호 조치를 취합니다. 중요 기보 독립적인 백업을 생성하려면 정기적으로 "다른 이름으로 저장"을 사용하는 것이 좋습니다.

참고:

- Gotepad 사용자 정의 속성을 임의로 수정하기 위해 텍스트 편집기를 사용하는 것은 권장되지 않습니다. 그렇지 않으면 UID 충돌이나 유형 오류로 인해 다시 로드가 실패할 수 있습니다.
- Gotepad에서 생성되지 않은 SGF의 경우 프로그램은 이러한 사용자 정의 속성을 맹목적으로 신뢰하지 않지만 범위를 충족하지 않는 값을 확인하거나 무시합니다.
- 불법 착수은 가져올 수 없습니다. SGF의 패스는 바둑판 상태 노드로 관리되지 않지만 저장 시 기보에서 요구하는 대로 생성됩니다.
- 외부 SGF 소프트웨어는 다층 음표 번호와 같은 Gotepad의 사용자 정의 데이터를 완전히 유지하지 못할 수 있습니다. 소프트웨어 간에 교환하기 전에 원본 파일을 보관하는 것이 좋습니다.

## 업데이트 확인

소프트웨어는 시작할 때 현재 플랫폼에 적용되는 새 버전을 한 번 자동으로 확인합니다. 업데이트가 발견되면 화면 맨 오른쪽의 **도구** 아래에 있는 **업데이트** 버튼 글자가 활성 탭 제목과 같은 금색으로 바뀝니다. 시작 시 확인은 결과 창을 자동으로 열지 않습니다. **업데이트**를 누르면 GitHub에 다시 연결하여 확인합니다. 확인이 끝나면 현재 버전, 업데이트 가능한 최신 버전, 그리고 해당 범위에서 최대 5개 적용 대상 버전의 업데이트 내용이 최신 버전부터 이전 버전 순서로 표시됩니다. 과거 버전에 별도의 GitHub Release가 없으면 해당 Tag의 버전 커밋 설명을 사용합니다. 다른 플랫폼 접두사가 붙은 릴리스는 무시됩니다. 현재 버전이 이미 최신이고 해당 GitHub Release가 남아 있으면 그 버전의 업데이트 내용도 표시됩니다.

정식 버전은 `i.j.k`로 표시되며 정식 업데이트만 받습니다. 테스트 버전은 `test/i.j.k`로 표시되며 테스트 및 정식 업데이트를 모두 받습니다. 공통 버전과 현재 플랫폼 전용 버전 중 기본 버전 번호가 가장 높은 것을 선택하고, 같은 번호에서는 정식 버전을 우선하므로 동일 번호의 테스트 버전에서 정식 버전으로 업데이트할 수 있습니다. 초안 릴리스는 업데이트 대상에서 제외됩니다.

오른쪽 위에서 **GitHub** 또는 **클라우드 드라이브**를 선택한 다음 **업데이트**를 누르면 시스템 기본 브라우저에서 해당 다운로드 페이지가 열립니다. Gotepad는 업데이트 확인과 페이지 열기만 수행하며 앱 안에서 업데이트를 다운로드하거나 설치하지 않습니다. GitHub에 연결할 수 없는 경우에도 결과 창에 오류가 표시되며 클라우드 드라이브 링크는 계속 사용할 수 있습니다.

## PPTX 내보내기

오른쪽 상단에 있는 "내보내기"를 클릭하고 '.pptx'를 선택하여 위치를 저장하세요. B5 가로 템플릿을 사용하여 내보내면 다음 콘텐츠가 레이아웃 페이지가 됩니다.

- 메모가 포함된 모든 국면;
- 동일한 국면의 각 메모 레이어;
- 메모가 없더라도 모든 가지 리프 노드를 강제로 내보냅니다.

바둑판은 흑백 출판 스타일을 사용하고 수 번호로 지정된 메모, 연속 문자 및 TR/SQ/CR/MA 그래픽 표시를 그립니다. 반복되는 착수 번호의 제목, 설명, 그림 제목 및 설명이 레이아웃에 기록됩니다.

내보내기는 현재 재생 경로뿐 아니라 전체 기보 트리를 순회합니다. 긴 댓글은 이어지는 페이지로 나뉘며 제목에 “（续）”가 붙습니다. 노트 포커스 모드는 노트 층별로 표시하며 내보내기의 이어지는 페이지 단위로 나누지 않습니다. SVG와 PNG 모두 페이지 수, 진행률 표시줄, “취소” 버튼을 표시합니다. 생성 중에 “취소”를 누르거나 `Esc`를 누르거나 진행 창을 닫으면 중단을 요청합니다. “내보내기 취소 중…”이 표시되고 현재 진행 중인 렌더링 등의 작업이 끝나 백그라운드 작업이 종료되면 창이 닫히며 다시 내보낼 수 있습니다. 마지막으로 대상 파일에 쓰는 동안에는 취소 버튼이 잠시 비활성화되므로 완료될 때까지 기다리세요. 내보내기 중에는 데스크톱의 메인 창 닫기도 잠시 차단됩니다. 성공 창은 스페이스, Enter 또는 `Esc`로 닫을 수 있습니다.

설정의 "바둑판 좌표 내보내기(왼쪽 및 위쪽)"는 내보낸 바둑판에 좌표가 있는지 여부를 제어할 수 있습니다. 활성화한 후에는 바둑판의 위쪽에 열 문자만 그려지고 왼쪽에는 행 번호가 그려집니다. 좌표는 바둑판에 가깝고 추가 공간 점유를 최소화하기 위해 가장자리 돌를 피합니다. 이 옵션은 기본적으로 꺼져 있으며 SVG 및 PNG 내보내기에 모두 적용됩니다.

### SVG 또는 PNG

"설정 → PPTX 바둑판 그림"에서 형식을 선택합니다.

| 형식 | 장점 | 메모 |
|---|---|---|
| SVG(기본값) | 벡터는 선명하고, 확대 및 인쇄 품질이 가장 좋으며, 일반적으로 파일 크기가 더 작습니다 | 일부 이전 버전의 PowerPoint, WPS 또는 호환 소프트웨어는 내장된 SVG를 표시하지 않을 수 있습니다 |
| PNG | 다양한 프레젠테이션 소프트웨어에서 안정적으로 표시 가능 | 바둑판은 1600×1600픽셀로 생성되며 일반적으로 파일이 더 크고 극단적인 확대도 SVG |

내보낸 파일이 새 버전의 PowerPoint에서 주로 사용되거나 고품질 인쇄에 사용되는 경우 SVG에 우선순위를 부여하세요. 알 수 없는 환경의 사용자에게 전송해야 하거나 바둑판 이미지가 표시되지 않는 문제가 발생한 경우 PNG를 선택하세요.

### 글꼴

PPTX의 바둑판 번호는 PNG 모드에서 래스터화되었지만 제목과 설명은 여전히 편집 가능한 텍스트입니다. 현재 내보낸 파일에는 글꼴이 포함되어 있지 않습니다. 편집 또는 인쇄 컴퓨터의 프로젝트에 포함된 Noto Sans CJK SC 및 Noto Serif CJK SC 글꼴을 설치하는 것이 좋습니다.

글꼴이 설치되어 있지 않으면 PowerPoint에서 해당 글꼴을 대체하므로 줄바꿈이나 레이아웃 변경이 발생할 수 있습니다.

## KataGo 분석

![KataGo 분석](../gotepad-gd/assets/ui/katago.svg)

Gotepad의 데스크톱 버전은 소프트웨어와 함께 KataGo 실행 파일 및 신경망 모델을 배포하지 않습니다. 사용하기 전에 설정에서 지정해야 합니다:

1. KataGo 분석 엔진 실행 파일
2. 이 버전과 호환되는 신경망 모델(보통 `.bin.gz`)
3. 분석 엔진에서 사용하는 `.cfg` 구성 파일.

설정이 완료되면 "경로 테스트"를 클릭하세요. "자동 성능 감지"를 실행하여 프로그램이 검색 스레드 수와 배치 크기를 추정하도록 할 수도 있습니다. TensorRT와 같은 백엔드는 처음 초기화할 때 시간이 오래 걸릴 수 있으며 감지에는 고정된 제한 시간이 없습니다. 현재 창의 약 80%를 차지하는 모달 창에서 자동으로 줄 바꿈되는 실시간 출력을 확인하고 직접 중지할 수 있습니다. 감지에 성공하면 결과 창에서 "적용"을 클릭하여 구성을 기록하고 설정을 바로 적용할 수 있습니다. "취소"를 클릭하거나 결과 창을 닫으면 실수로 다시 감지해야 하는 상황을 방지하도록 먼저 확인 메시지가 표시됩니다. 감지 중에는 다른 설정을 일시적으로 조작할 수 없습니다.

### 현재 국면 분석

KataGo 패널을 연 후:

- 재생 버튼을 누르면 현재 국면 분석이 시작되며, 설정된 새로 고침 간격에 따라 결과가 업데이트됩니다.
- 일시 중지 버튼은 인터페이스 새로 고침만 일시 중지하고 KataGo는 계속 계산합니다. 재개하면 최신 결과가 표시됩니다.
- 중지 버튼은 현재 분석을 종료하라는 요청을 엔진에 보냅니다.
- “연산량 늘리기”는 오른쪽 입력란의 `maxplayouts`로 현재 국면을 다시 분석하며 값은 양수여야 합니다. 위아래 화살표의 증감 폭은 저장된 “분석 연산량”과 같고 해당 설정을 저장하면 갱신됩니다. 정수를 직접 입력할 수도 있습니다. 실행 중에도 화면 갱신을 일시 정지하거나 분석을 중지할 수 있습니다.
- "지속 분석"을 활성화하면 새 국면으로 이동할 때 자동으로 다시 분석합니다. 이때 재생, 일시 정지 및 정지 버튼은 지속 모드에서 제어합니다. 기보 탭을 전환하거나 현재 기보를 닫으면 지속 분석이 자동으로 중지되므로 전환한 기보에서 계속 실행되지 않습니다.

Android 버전은 현재 국면 분석, 연속 분석 및 전체 재생 경로 분석의 결과 진행 상황을 감시합니다. 앱이 백그라운드에 있는 동안에는 감시를 일시 중지하고 포그라운드로 돌아오면 시간을 다시 계산합니다. KataGo가 오랫동안 결과를 반환하지 않으면 OpenCL 분석 서비스를 자동으로 다시 시작하고 완료되지 않은 요청을 복구합니다. 자동 복구 후에도 응답이 없으면 현재 분석을 중지하고 다시 시작하라는 안내를 표시합니다.

후보 표에는 위치, 현재 차례인 쪽의 승률, 집 차이와 변화도 진입 항목이 표시됩니다. 상위 3개 후보는 반투명한 짙은 녹색, 연한 녹색, 노란색으로 바둑판에 표시되며, "추가 바둑판 후보 수"로 밝은 노란색 후보를 0~99개 더 표시할 수 있습니다. "상위 3개 후보 불투명도"와 "기타 후보 불투명도"에서 두 후보 그룹의 불투명도를 각각 조절할 수 있습니다. "집 차이 표시"를 활성화하면 다음 줄의 "바둑판 후보에 집 차이 표시"도 선택할 수 있습니다. 이 옵션을 켜면 각 후보 표식 위쪽에는 현재 차례인 쪽의 승률, 아래쪽에는 집 차이가 표시되고 가운데는 가로선으로 구분됩니다. "집 차이 표시"를 끄면 "바둑판 후보에 집 차이 표시"도 함께 꺼지고 비활성화됩니다. 후보 위치가 현재 기보 경로의 실제 다음 수와 일치하면 추가 후보를 포함해 얇은 검은색 테두리가 표시됩니다. 전체 기보 경로가 분석된 상태에서 실제 다음 수가 상위 3개 후보에 없고 그 수를 둔 뒤의 승률이 1순위보다 10%포인트 이상 낮으면, 실제 다음 수 위치에 옅은 빨간색 원으로 음수 승률 차이를 표시합니다. 표의 "진입"을 누르면 후보 수순을 변화도에 불러옵니다. 바둑판이 잠겨 있을 때는 판 위 후보 표시를 직접 눌러 해당 변화도에 진입한 뒤 유지하거나 버릴 수 있습니다.

### 전체 재생 경로 분석

“전체 재생 경로 분석”을 누르면 “전체 대국 빠른 분석량”으로 각 국면의 승률과 집 차이 곡선을 생성합니다. 현재 경로만 분석하며 다른 곁가지는 분석하지 않습니다. 분석 중에는 버튼이 “전체 대국 분석 취소”로 바뀌며 다시 누르면 중지합니다. 이미 받은 결과는 유지됩니다. 기본 계산량은 추세를 빨리 보기 위한 낮은 값이므로 정밀한 판단으로 받아들이지 마세요. 세로선은 현재 국면을 나타내며 곡선의 다른 위치를 누르면 이동합니다. KataGo 패널을 닫으면 현재 국면과 전체 분석을 중지하고 지속 분석도 해제합니다.

KataGo의 승률과 집 차이는 규칙, 덤, 모델, 계산량 및 하드웨어의 영향을 받습니다. 방문 횟수가 적으면 결과가 크게 변동할 수 있으므로 중요한 결론은 계산량을 늘려 확인하세요. 데스크톱 버전은 사용자가 설정한 외부 KataGo 엔진을 사용합니다. Android 버전은 기기의 OpenCL GPU 백엔드를 우선 사용하며, OpenCL을 사용할 수 없거나 백엔드가 시작되지 않으면 호환성이 높은 Eigen CPU 백엔드로 자동 전환합니다. iOS 버전은 내장 KataGo Metal GPU 백엔드와 10b 모델을 사용하므로 실행 파일을 지정할 필요가 없습니다. 앱이 백그라운드로 이동하면 분석이 중지되며, 다시 전면으로 돌아온 뒤 분석을 시작할 수 있습니다. Android와 iOS의 종국 계가는 일반 분석에서 선택한 외부 모델이나 Human SL 모델 대신 내장 10b 모델과 별도 설정을 사용합니다. “계가 계산량” 설정은 그대로 적용됩니다. 계가를 시작하면 다른 분석 엔진을 해제하고, 계가 종료 후 다시 분석할 때 원래 선택한 모델을 다시 불러옵니다. 계가 중 앱이 백그라운드로 이동하면 계가 모드가 종료됩니다. iOS에서도 외부 모델을 가져오고 일반 분석 또는 Human SL 자동 성능 감지를 실행할 수 있습니다. 감지가 끝나면 “적용”을 눌러 권장 스레드 수와 배치 크기를 저장하세요. 감지 중에는 앱을 전면에 유지하세요. 백그라운드로 이동하면 감지가 중단됩니다.

## 인간 모방 대국

![인간 모방 대국](../gotepad-gd/assets/ui/katago_human_play.svg)

현재 바둑판에서 Human SL 모델 대국로 시작하려면 일반 KataGo 아이콘 아래에 있는 인간 모방 대국 아이콘을 클릭하세요. 시작하기 전에 AI가 흑백, 현대 또는 AlphaGo 이전 기풍을 재생하는지, 기력를 시뮬레이션하는지, 손당 AI 계산 금액을 선택할 수 있습니다. 계산량 입력 상자에는 "인간 모방 대국 계산량" 설정의 현재 방문 값이 표시되며 대화 상자의 임시 조정은 이 대국에만 적용됩니다. 값이 낮을수록 더 빠르지만 마스터 모델이 평가할 인간 후보가 적어서 중대한 실수가 발생할 가능성이 더 높습니다. 값을 높이면 선택된 인간을 계속 유지하면서 과도한 손실을 입은 후보자를 더 완전히 억제합니다. 현대 및 AlphaGo 이전 기풍의 9단은 명백한 실수를 억제하기 위해 주 모델 평가에 더 엄격한 가중치를 적용하며, 다른 기력은 기존 착수 선택 방식을 유지합니다. 프로그램은 현재 바둑판를 유지하므로 이미 기보이 있는 중간 국면을 AI에 넘겨 인수할 수 있습니다.

인간 모방 대국 모드에 들어가면 KataGo 분석 패널이 자동으로 열립니다. 인간 모방 대국는 임시 기보을 사용하고 진행률 표시줄과 일반 바둑판 도구는 일시적으로 숨겨지며 KataGo 분석, 종국 계가, 무르기, 유지 및 포기 버튼만 유지됩니다. 현재 국면 연산, 후보 테이블, 분석 패널 오른쪽 하단에 있는 전체 기보 빠른 분석 버튼은 모두 작동 불가능하지만, 승률, 집 차이 곡선은 대국 결과로 계속 업데이트됩니다. 인간 모방 대국 중에는 마우스 휠, 방향키, 재생 막대, 앞뒤 이동 버튼 또는 분석 곡선으로 기보를 탐색할 수 없습니다. 사람의 차례에는 전용 무르기 버튼으로만 직전의 사람 착수와 그 뒤의 AI 응수를 한꺼번에 취소할 수 있으며, AI가 생각하는 동안에는 무르기를 할 수 없습니다. 모드 종료 후 분석 패널은 진입 전의 열림 또는 닫힘 상태로 돌아갑니다. 대국 도중 기보 탭을 전환하거나 새 기보를 만들면 현재 대국을 보존하고 계속할지, 버리고 계속할지, 작업을 취소할지 묻습니다. AI가 생각 중이라면 확인창이 열려 있는 동안 탐색을 일시 중지하고 작업을 취소하면 다시 시작합니다.

분석 패널의 상태 메시지에는 현재 휴먼 SL 장비 앞에 '[랭크_1d] AI가 생각하고 있습니다...'와 같이 앞에 붙습니다. `rank_'는 현대의 기풍을 나타내고, `preaz_`는 알파고가 등장하기 전의 기풍을 나타내며, 후반부는 이 게임이 선택한 기력를 나타낸다.

AI가 패스를 선택하면 프로그램은 사용자에게도 패스할지 묻고, 별도의 패스 버튼은 제공하지 않습니다. 계속 착수하기를 선택하면 바둑판에서 대국을 이어갈 수 있습니다. 양쪽이 모두 패스한 후에는 종국 계가로 결과를 확인할 수 있습니다. 설정에서 "AI 기권 제안"을 활성화하면 연속된 승패 평가와 현재 집 차이를 함께 사용해 흑과 백 양쪽을 판단합니다. 최소 수수에 도달하기 전에도 연속 평가는 누적되지만 조기에 알림을 표시하지는 않습니다. 내부 기권 조건을 충족해도 알림만 표시하며 어느 쪽도 자동으로 기권시키거나 대국을 종료하지 않습니다. 계속 진행하거나 대국을 보존 또는 버릴지는 사용자가 결정할 수 있습니다. 알림을 표시할 때마다 흑백 양쪽의 연속 판단 기록을 모두 지우고 처음부터 다시 누적합니다. 녹색 `✓`을 누르면 현재 대국을 종료하고 이번 수순을 원래 기보에 기록할지 확인한 뒤 실행합니다. 빨간색 `✕` 또는 `Esc`는 확인 후 이번 대국 기록을 버립니다.

## 종국 계가

![종국 계가](../gotepad-gd/assets/ui/territory_scoring.svg)

종국 계가는 현재 중국식 규칙만 지원합니다. 사용하기 전에 모든 공배를 메운 뒤 바둑판 오른쪽 도구 모음 끝에 있는 종국 계가 아이콘을 누르세요. 계가 중에는 돌 위의 수 번호가 일시적으로 숨겨지며, 계가를 종료하면 원래 표시 설정으로 돌아갑니다. 프로그램은 설정의 "종국 계가 계산량"에 따라 KataGo에 각 교차점의 흑백 소유권 판정을 요청합니다. 이 계산량의 기본값은 200 visits이며 일반 분석 계산량 및 인간 모방 대국 계산량과 별개입니다. 판정 결과는 바둑판 위에 반투명 영역 표시로 나타납니다. 녹색 `✓`와 빨간색 `✕` 옆의 독립 로그 패널에는 엔진 시작 정보와 실시간 판정 진행 상황이 한 줄씩 표시됩니다.

KataGo는 사활과 소유권을 잘못 판단할 수 있습니다. 교차점을 누르면 상하좌우로 연결된 같은 소유권 영역 전체를 반대편으로 바꿉니다. 표시를 확인하고 녹색 `✓`를 누르면 계산용 바둑판에서 죽은 돌을 제거하고 남은 빈 영역을 판정하여 흑백의 돌 수, 빈 점 수, 덤, 중립점, 승패와 집 차이를 표시합니다. 백의 합계에는 덤이 포함됩니다. 계가 모드를 종료하고 결과를 표시할 뿐 원래 기보의 돌을 삭제하거나 기보 결과를 자동 입력하지 않습니다. 빨간색 `✕` 또는 `Esc`도 기보를 수정하지 않고 종료합니다. 계가는 보조 확인용이며 복잡한 사활, 빅, 미완성 공배는 사용자가 확인해야 합니다.

## 설정

오른쪽 상단의 톱니바퀴 버튼을 클릭하거나 `Ctrl+O`를 누르세요. 설정을 수정한 뒤 패널 왼쪽 상단의 녹색 `✓`으로 저장하고, 파란색 `↺`으로 이번 변경을 되돌리며, 빨간색 `✕`으로 취소하고 닫을 수 있습니다. 왼쪽의 `∧`, `∨` 버튼을 사용하여 현재 보이는 설정 영역 높이의 3분의 2만큼 위아래로 부드럽게 스크롤할 수 있습니다.

### 인터페이스 언어

"인터페이스 언어"에서는 중국어, 일본어, 한국어, 영어를 선택할 수 있습니다. 옵션을 바꾸면 즉시 해당 언어를 미리 볼 수 있고, 녹색 `✓`으로 저장하면 다음 실행에도 유지됩니다. 파란색 `↺`, 빨간색 `✕` 또는 패널 닫기를 사용하면 설정을 열었을 때의 언어로 돌아갑니다. 버튼, 안내 메시지, 도구 설명과 `[GNE…]` 번호가 붙은 핵심 명령 메시지는 선택한 언어를 따르지만, 기보 제목, 노트, 파일명, KataGo 원본 로그와 SGF 내용 자체는 번역되지 않습니다. 데스크톱 네이티브 파일 선택기에서는 제목, 확인 버튼 및 파일 형식 설명이 Gotepad의 현재 언어를 사용하며, 그 밖의 시스템 제공 문구는 운영 체제 언어로 남을 수 있습니다.

### 외관 및 재생

- 바둑판 질감: 밝은 나뭇결과 어두운 나뭇결을 전환합니다.
- 돌 질감: 광택 또는 무광택 흑백 돌로 전환합니다.
- 화면 왼쪽 및 오른쪽 여백(모바일의 경우): 픽셀 단위로 바둑판, 탭 막대, 버튼 및 패널을 화면 왼쪽 및 오른쪽 가장자리에서 동시에 멀리 유지하고 대칭으로 적용합니다. 기본값은 '0px'입니다. 둥근 모서리나 컷아웃이 있는 가로 방향 장치에서는 컨트롤이 완전히 표시될 때까지 이 값을 점진적으로 늘릴 수 있습니다. 배경 텍스처는 여전히 전체 화면을 채웁니다.
- 바둑판 가로 너비 비율: 원래 사용 가능한 가로 공간의 최대 비율을 사용하도록 바둑판을 제한합니다. 허용 범위는 '50%~100%'이며, 기본값은 '100%'입니다. '4:3'과 같이 수평 공간이 좁은 화면에서는 적절하게 조정하여 메모와 KataGo 분석 패널을 위한 더 많은 공간을 확보할 수 있습니다. 바둑판은 가장자리가 잘리지 않고 완전히 표시됩니다.
- UI 배율: 활성화하면 창 높이에 따라 선형으로 계산된 UI 배율에 오른쪽에서 지정한 배율을 곱합니다. 기본값은 `1.5`배이며 휴대폰과 태블릿의 터치 조작에 편리합니다. 허용 범위는 `0.50～2.00`입니다. 증감 버튼은 한 번에 `0.1`씩 변경하며 직접 입력할 때는 소수점 이하 두 자리까지 지원합니다. 범위를 벗어난 값은 적용되지 않습니다. 데스크톱 버전에서도 사용할 수 있습니다.
- 수 번호 표시: 최근 1수, 10수, 모든 수 또는 지정 수를 표시합니다. 기본값은 최근 1수이며 지정 범위는 1~9999수, 초기 지정 값은 20입니다.
- 절대 수 번호: 현재 분기의 절대 착수수 번호을 사용하고, 그렇지 않으면 상대 번호를 표시합니다.
- 재생 간격: 자동 재생의 각 단계 대기 시간으로 0.1~60초이며 기본값은 1초입니다.
- 착수 사운드 효과: 0-100 슬라이더를 사용하여 조정합니다. 기본값은 50이며, 0으로 설정하면 음소거됩니다. 프로그램은 5개의 실제 바둑착수 녹음을 무작위로 재생합니다. 새로운 착수이 성공적으로 생성되어 다음 착수 노드로 로밍되면 재생됩니다. 기보 로드, 사전 설정된 노드로 로밍 및 사전 배치 돌이 트리거되지 않습니다.
- 착수 확인: 먼저 반투명한 대기 중인 돌을 표시하며, 녹색 `✓` 아이콘을 누르거나 같은 위치를 다시 클릭하여 착수를 확정할 수 있습니다. 데스크톱에서는 기본적으로 꺼져 있고 모바일에서는 기본적으로 켜져 있습니다.
- PPTX 바둑판 이미지: SVG와 PNG 간 전환, 기본값은 SVG입니다.
- 바둑판 좌표 내보내기: PPTX 바둑판 위쪽에 열 문자를 표시하고 왼쪽에 행 번호를 표시합니다. 기본값은 꺼져 있습니다.

### KataGo

- 분석 계산량: 현재 국면의 `maxVisits`로 1~100000이며 기본값은 5000입니다.
- 종국 계가 계산량: 소유권 판정의 `maxVisits`로 1~100000이며 기본값은 200입니다. 일반 분석 계산량과 독립적입니다.
- 분석 갱신 간격: 중간 결과 수신 간격으로 0.1~60초이며 기본값은 1초입니다.
- 후보 변화도 수순: 후보 PV를 표시하고 변화도로 가져오는 최대 수로 1~1000이며 기본값은 10입니다.
- 추가 보드 후보 수: 상위 3개 후보 외에 표시되는 보드 후보 수로, 범위는 0~99이며, 기본값은 0입니다.
- 상위 3개 후보 불투명도: 상위 3개 바둑판 후보 표시의 불투명도입니다. 범위는 0%~100%, 기본값은 70%이며 화살표를 누를 때마다 10%씩 조절됩니다.
- 기타 후보 불투명도: 추가 바둑판 후보 표시의 불투명도입니다. 범위는 0%~100%, 기본값은 30%이며 화살표를 누를 때마다 10%씩 조절됩니다.
- Display 집 차이: 후보 테이블과 곡선이 집 차이을 표시할지 여부를 제어합니다.
- 바둑판 후보 집 차이 표시: “집 차이 표시”가 켜져 있을 때 선택할 수 있으며 기본적으로 꺼져 있습니다. 후보 표시에 승률과 집 차이를 함께 표시합니다. “집 차이 표시”를 끄면 이 옵션도 꺼집니다.
- 전체 기보 빠른 분석 계산량: 국면별 visits로 1~100000이며 기본값은 속도 우선의 1입니다.
- 테스트 경로: 실행 파일, 모델 및 구성을 시작할 수 있는지 확인합니다.
- 자동 성능 감지: KataGo가 감지를 완료하거나 사용자가 중지할 때까지 계속 실행하여 현재 장치에 적합한 매개변수를 추정합니다. 실행 중에는 모달 창에 벤치마크 출력이 표시되며, 완료 후에는 창에서 결과를 바로 적용하거나 추가 확인을 거쳐 취소할 수 있습니다.

분석 설정을 저장해도 기존 후보 결과와 승률 및 집 차이 곡선은 유지됩니다. 실행 중인 이전 분석 요청은 중지되지만, 지속 분석이 켜져 있었다면 새 설정으로 자동 재시작됩니다. 전체 기보 빠른 분석은 자동으로 다시 실행되지 않습니다. 다시 실행하면 새 결과가 기존 곡선을 순차적으로 덮어씁니다. KataGo 실행 파일, 모델 또는 설정을 변경한 뒤에는 새 결과로 대체될 때까지 유지된 결과가 변경 전 엔진 설정에서 생성된 것임에 유의하십시오.

자동 성능 테스트 결과 창의 “적용”은 설정 패널의 다른 미저장 변경도 함께 저장합니다. 적용 전에 모두 확인하세요. 인간 모방 대국 계산량은 1~100000 visits이며 기본값은 200입니다.

설정을 열 때 저장된 KataGo 경로가 유효하지 않게 되면 인터페이스에서 경로가 지워지고 다시 선택해야 합니다. 자동으로 생성된 성능 구성은 Godot의 사용자 데이터 디렉터리에 저장되며 Windows, Linux 및 macOS의 권한 차이를 수용하기 위해 설치 디렉터리에 기록되지 않습니다.

“KataGo 인간 모방 대국”은 별도의 설정 영역입니다. 데스크톱 버전에서는 현재 KataGo 실행 파일과 호환되는 Human SL `.bin.gz` 모델을 선택해야 합니다. Android와 iOS에서는 시스템 파일 선택기로 모델을 가져오며, 가져온 파일은 앱이 관리합니다. Human SL 모델을 일반 분석 모델로 대체할 수 없습니다. 일반 분석과 인간 모방 대국에 사용하는 모델의 용도는 서로 다릅니다. 모바일 버전에서는 모델을 가져오거나 엔진을 시작할 때 모델 내부의 유형 표시를 확인하고, 잘못된 유형을 선택하면 안내를 표시합니다. 파일 이름으로 모델의 용도가 결정되지는 않습니다. Android와 iOS의 인간 모방 대국은 일반 분석에 외부 모델을 선택했더라도 내장 10b 모델을 주 분석 모델로 사용합니다. 데스크톱 버전은 선택한 주 분석 모델을 계속 사용합니다. “인간 모방 대국 계산량”은 새 대국의 기본 방문 횟수이자 자동 성능 감지의 실제 부하이므로, 변경 후에는 이 영역에서 성능 감지를 다시 실행해야 합니다. “AI 기권 제안”은 기본적으로 꺼져 있으며, 활성화해도 대국 중 기권 안내만 추가하고 대국을 자동으로 조작하지 않습니다. 성능 감지는 인간 모방 대국용 별도 설정을 생성하며 일반 분석 모델의 감지 결과를 직접 재사용하지 않습니다.

인간 모방 대국 성능 테스트를 시작하면 프로그램은 먼저 설정 패널의 모델 경로를 확인합니다. 경로가 아직 저장되지 않았거나 현재 적용된 경로와 다르면 경로를 먼저 저장하고 계속할지 묻습니다. 확인 후에는 파일이 실제로 존재하고 읽을 수 있으며 지원되는 형식인지도 검사합니다. 검사에 실패하면 유효한 모델을 다시 선택해야 합니다. 성능 테스트에 성공한 뒤 결과 창에서 "적용"을 클릭하면 새로 생성된 성능 구성이 기록되어 바로 적용됩니다. 결과를 취소하기 전에는 다시 한번 확인 메시지가 표시됩니다.

Android와 iOS에서 일반 분석 또는 Human SL 모델을 가져올 때 파일 크기는 1 KB~1 GB여야 하며 모델 크기의 두 배 이상인 저장 공간이 필요합니다. 가져온 뒤 설정을 저장해야 합니다. 설정을 취소하면 이번에 가져온 모델은 활성화되지 않습니다.

## Android 및 iOS 버전

현재 Android 버전은 Android 9 이상이 설치된 arm64-v8a 기기를 지원하며 가로 방향 사용을 위해 설계되었습니다. APK 파일을 기기에 복사하여 설치하세요. 시스템이 설치를 차단하는 경우 시스템 메시지에 따라 해당 소스에서 애플리케이션을 설치할 수 있도록 허용해야 합니다.

Android와 iOS의 설정 패널, 인간 모방 대국 시작 대화 상자, KataGo 분석 패널에서 숫자 입력란을 짧게 누르면 키보드가 열리지 않습니다. 숫자 영역을 0.5초 동안 길게 누르면 키보드 입력이 시작됩니다. 노트 제목, 노트 본문, 대국 정보 패널의 텍스트 입력란도 같은 길게 누르기 방식을 사용하므로 짧게 누르거나 드래그할 때 키보드가 즉시 열리지 않습니다. 오른쪽의 값 조정 버튼은 폭을 넓히고 화살표도 키워 터치하기 쉽게 했으며, 기존 행 높이는 변경하지 않았습니다.

Android 버전에는 실행 파일이나 구성 경로를 선택할 필요 없이 KataGo OpenCL/Eigen 분석 백엔드, 모델 및 내부 관리 구성 파일이 내장되어 있습니다. 현재 APK에 내장된 모델은 'g170e-b10c128-s1141046784-d204142634'이며 KataGo g170 확장 학습의 10블록/128채널 네트워크에 속합니다. g170 훈련 배치에 컴퓨팅 성능과 데이터를 제공하고 관련 모델 데이터를 CC0에 따라 공개 도메인에 제공한 Jane Street 및 KataGo 작성자 David J. Wu(lightVector)에게 감사드립니다. 또한 모델의 다운로드 이미지를 제공한 pachi 프로젝트에도 감사드립니다. 설정의 "신경망 모델"은 기본적으로 내장 모델을 사용합니다. "찾아보기"를 클릭하여 Android 시스템 파일 선택기를 통해 표준 KataGo `.bin.gz` 또는 `.txt.gz` 가중치를 가져올 수도 있습니다. 가져오기 프로세스는 모델을 Gotepad의 애플리케이션 데이터 디렉토리에 복사하므로 원본 파일의 후속 이동 또는 삭제는 사용에 영향을 미치지 않습니다. 대형 모델을 가져오기 전에 장치에 충분한 저장 공간과 실행 메모리가 있는지 확인하세요. BadukAI와 같은 소프트웨어에서 사용되는 이중 파일 Android 최적화 모델은 표준 KataGo 가중치가 아니므로 여기에 직접 로드할 수 없습니다. 소프트웨어와 함께 제공된 모델로 다시 전환하려면 "내장"을 클릭하고 녹색 `✓`으로 저장하세요. 프로그램은 장치에 의해 노출된 OpenCL GPU 백엔드 사용에 우선순위를 부여합니다. 장치에 사용 가능한 OpenCL 구현이 없거나, 드라이버 초기화가 실패하거나, 독립 분석 프로세스가 비정상적으로 종료되는 경우 자동으로 Eigen CPU 백엔드로 대체됩니다. 분석 계산량, 새로 고침 간격, 후보 변화도수 번호, 집 차이 표시 및 전체 기보 빠른 분석 계산량과 같은 옵션은 계속 조정할 수 있으며 자동 성능 감지도 실행할 수 있습니다. 감지가 완료되면 결과 창에서 "적용"을 클릭하여 결과를 내부 구성에 바로 기록할 수 있습니다. OpenCL 백엔드는 처음 실행하거나 모델을 변경할 때 현재 GPU에 맞게 조정해야 하므로 후속 출시보다 속도가 상당히 느려질 수 있습니다. 분석하면 전력 소비와 발열이 증가합니다. 장시간 분석 시에는 기기 온도에 주의하는 것이 좋습니다.

Android 설정에는 기본적으로 꺼져 있는 “특정 모델 가속” 옵션이 있습니다. 구조가 호환되는 모델의 19×19 분석에 사용합니다. 전체 트렁크, 중첩 잔차 블록, 어텐션, FFN, 출력 헤드를 순회하여 실제 구조와 연산 크기로 최적화 경로를 선택하며, 파일 이름이나 내부 이름, 학습 체크포인트로 판단하지 않습니다. 옵션을 켠 뒤 녹색 `✓`으로 저장하고 자동 성능 감지 또는 일반 분석을 실행하세요. 옵션을 끄고 저장하면 원래 구현으로 돌아갑니다. 모델, 바둑판 크기 또는 계산 조건이 요구 사항에 맞지 않으면 원래 구현을 사용하며, 칩이나 GPU 모델명에 따른 제한은 없습니다. 실험적인 기능이므로 실제 속도 향상 여부는 기기에서 측정해야 합니다. 옵션을 끈 상태와 켠 상태에서 각각 자동 성능 감지를 실행하고, 같은 국면의 분석 결과에 눈에 띄는 이상이 없는지도 확인하세요. 성능 감지 창에는 이번 실행에 적용되는 저장된 설정이 표시됩니다. 체크만 하고 저장하지 않으면 적용되지 않습니다. 모델을 불러온 뒤 실제 측정을 시작하기 전에 모델 내부 이름, 구조 호환 여부, 후보 커널 수, 백엔드의 실제 가속 활성화 상태도 표시됩니다. 초기화 실패나 실행 중 원래 구현으로 복귀한 경우에도 안내합니다. 옵션 옆의 `?` 버튼에서 현재 지원 모델, 검증 진행 상황, 비교 방법을 확인할 수 있습니다. 초기 개발과 테스트는 XRing O3에서 진행했으며, 다른 GPU에서의 성능 향상은 보장되지 않습니다. 같은 기기에서 이 기능을 끄고 켜면서 매번 저장한 뒤 자동 성능 감지를 실행하여 결과를 비교하세요. 새로운 기기에서는 수치 검증도 권장합니다.

초기 구현에서는 XRing O3에서 tf2-b10c384와 b18c384nbt의 속도 향상 및 수치 비교를 확인했습니다. 새 구조 판별은 형식 버전 14~17 중 메타데이터 입력이 없고 호환 연산이 있는 합성곱, NBT, Transformer 및 혼합 네트워크를 대상으로 하며, 학습 체크포인트나 블록 수, 채널 너비를 고정하지 않습니다. 행렬 입력 채널은 16의 배수, 출력 채널은 32의 배수여야 하며 배치 크기는 1~32입니다. 배치 형식이 호환되는 1×1 합성곱과 투영을 가속하며, QKV 및 SwiGLU 융합에는 차원 일치 조건도 적용됩니다. 나머지 연산은 원래 구현을 사용합니다. 구조 호환은 모든 연산의 교체나 수치·성능 검증 통과를 뜻하지 않습니다. 새 경로에서 더 많은 연산이 교체될 수 있으므로 이전에 테스트한 모델도 다시 검증해야 합니다.

특정 모델 가속을 사용하려면 백엔드에서 FP16 저장이 활성화되어 있어야 합니다. 실험 커널은 기기의 FP16 지원 능력을 독립적으로 확인하고 컴파일을 시도하므로, 이제 원래 백엔드에서도 FP16 계산을 사용해야 하는 것은 아닙니다. 자동 튜닝에서 FP16 계산이 선택되지 않았더라도 기기가 FP16을 지원하지 않거나 실험 커널이 반드시 더 느리다는 의미는 아닙니다. 성능 감지에서는 FP16 저장 비활성화, 기기 성능 요건 미충족, 커널 컴파일 실패 등의 원인을 구분하여 표시합니다. 실험 경로와 원래 구현은 서로 다른 계산 정밀도를 사용할 수 있으므로, 새로운 기기에서는 속도를 비교하기 전에 먼저 수치 검증을 실행하세요.

Android 버전에는 “수치 검증” 버튼도 있습니다. 먼저 구조가 호환되는 분석 모델을 선택하고 저장한 뒤 이 버튼을 누르세요. 프로그램은 현재 분석을 일시 중지하고, 고정된 절차로 생성한 합법적인 국면 32개를 사용하여 배치 크기 1, 2, 4, 8, 16, 32에서 원래 구현과 실험 구현을 자동으로 비교합니다. 반복 실행의 재현성과 개별 평가 및 배치 평가 사이의 일관성도 확인합니다. 검증 중에는 성능 진단이 자동으로 꺼지고 두 구현 사이를 자동으로 전환하므로 가속 옵션을 직접 전환할 필요가 없습니다. 저장된 스레드 수, 배치 크기, 옵션 설정도 변경하지 않습니다. 창에는 착수 확률, 승률, 집 차이, 소유권 예측의 최대 차이와 보고서 경로가 표시됩니다. 승률과 착수 확률은 0~1 범위이며, 집 차이는 집 단위입니다. “중지”로 검증을 중단할 수 있지만, 완료되지 않은 보고서를 검증 통과의 근거로 사용할 수는 없습니다. “완료, 보고서 검토 대기”는 데이터 수집이 끝났다는 뜻일 뿐, 수치의 정확성이 확인되었다는 뜻은 아닙니다. 또한 생성된 국면만으로 실제 기보의 패싸움이나 사활 등에 대한 별도 검증을 대신할 수는 없습니다.

“성능 진단(속도에 영향)”은 별도의 옵션이며 기본적으로 꺼져 있습니다. 성능 문제를 조사하기 위한 정보가 필요할 때 켜고 녹색 `✓`으로 저장한 뒤 분석 모드로 들어가세요. 같은 국면을 최소 1분간 분석하고, 필요하면 분석 계산량을 늘리세요. 진단에는 추가 처리 비용이 발생하므로 활성화된 상태에서 표시되는 속도를 일반적인 성능 결과로 보아서는 안 됩니다. 수집을 마치면 옵션을 끄고 저장하세요. 자동 성능 감지는 항상 이 진단을 끄지만, 저장된 가속 설정은 사용합니다. Android에서는 자동 성능 감지 보고서와 진단 로그를 실행별로 따로 저장하므로 나중에 가져와 분석할 수 있습니다. 두 모델이나 가속 옵션의 활성화 전후를 비교할 때는 같은 기보 국면을 사용하고, 기기 온도, 전원 공급, 화면 상태를 최대한 동일하게 유지하세요.

Android의 성능 감지, 성능 진단 및 수치 검증 기록 로그는 기존 앱 전용 외부 파일 디렉터리의 `o3-profile` 폴더에 저장됩니다. 프로그램은 시작 후와 실행 중에 기록을 확인하고, 백엔드가 종료되어 로그 기록이 멈춘 뒤 오래된 항목부터 정리합니다. 최대 20개 그룹, 합계 200 MiB 이하를 유지하는 것이 목표입니다. 한 번의 수치 검증에서 생성된 각 배치 보고서와 요약은 하나의 그룹으로 처리하며, 그룹 표시가 없는 이전 버전의 검증 보고서는 합쳐서 보관하거나 정리합니다. 진행 중인 작업은 삭제하지 않고 최신 그룹도 유지하므로 용량이 일시적으로 제한을 초과할 수 있습니다. 단일 성능 진단 파일이 약 20 MiB에 도달하면 잘림 표시를 기록하고 이후 샘플링을 중지하지만, 기보 분석은 계속 실행됩니다. 새 로그를 수집하려면 분석을 중지한 뒤 다시 시작하세요. 장기간 보관하거나 문제 조사에 제출할 보고서는 다른 위치에 신속히 복사하세요. 이러한 기록 로그는 시스템의 “캐시 지우기” 기능으로 정리되지 않습니다.

Android 버전은 시스템 파일 선택기를 통해 SGF를 로드하거나 시스템 클립보드에서 전체 SGF 텍스트를 붙여넣을 수 있습니다. 중국어, 일본어, 한국어 등의 파일명과 기보 내용을 정상적으로 표시할 수 있습니다.

iOS 버전에서는 새 기보 화면에서 “불러오기”를 누르면 시스템 파일 선택기가 열리며, 파일 앱의 기기 내 저장소, iCloud Drive 또는 활성화된 다른 파일 제공자에서 `.sgf` 파일을 선택할 수 있습니다. 파일 앱이나 “다음으로 열기/공유”를 지원하는 다른 앱에서 Gotepad를 선택하여 SGF를 열 수도 있습니다. 앱이 실행 중이 아니면 시작하여 파일을 불러오고, 이미 실행 중이면 새 탭에서 엽니다. iOS는 원래 파일 이름을 유지한 복사본을 가져오므로 편집해도 원본 파일을 직접 덮어쓰지 않습니다. 첫 저장과 “다른 이름으로 저장”에서는 시스템 파일 화면에서 저장 위치를 선택합니다. 저장에 성공하면 이후 “저장”은 선택한 파일을 업데이트합니다. 파일이 이동했거나 권한이 만료되었거나 파일 제공자가 쓰기를 지원하지 않으면 “다른 이름으로 저장”으로 위치를 다시 선택하세요. PPTX 내보내기는 먼저 교재를 생성한 뒤 시스템 파일 화면에서 저장 위치를 선택합니다. 선택을 취소하면 교재는 저장되지 않습니다. iOS 새 기보 화면에서 “이미지”를 누르면 “사진” 또는 “파일”을 선택할 수 있습니다. 사진에서는 사진과 스크린샷을 선택하고, 파일에서는 기기 내 저장소, iCloud Drive 또는 다른 파일 제공자의 이미지를 선택할 수 있습니다. 사진 선택기는 선택한 이미지만 읽으므로 사진 보관함 전체에 대한 권한이 필요하지 않습니다. 선택을 취소하면 새 기보 화면으로 돌아갑니다. iOS에서도 바둑판 이미지 자동 인식과 네 모서리 및 돌 위치 교정을 지원합니다. “촬영”을 처음 사용하면 카메라 권한을 요청합니다. 이전에 거부했다면 시스템 설정에서 Gotepad의 카메라 사용을 허용하세요. 촬영한 이미지는 바둑판을 가져오는 데만 사용하며 시스템 사진 보관함에 자동 저장되지 않습니다.

"다음으로 열기" 시스템을 지원하는 Android 파일 관리자 또는 기타 애플리케이션은 Gotepad를 사용하여 SGF를 직접 열 수 있습니다. 애플리케이션이 실행되고 있지 않으면 시작되어 기보이 로드됩니다. 애플리케이션이 이미 실행 중이면 새 탭에서 열립니다. 이미 열려 있는 동일한 기보이 기존 탭으로 전환됩니다. 외부 애플리케이션에서 제공하는 파일에는 읽기 권한만 있을 수 있습니다. 이 경우 도구 모음의 "저장"은 저장할 새 위치를 선택하도록 자동으로 변경되며 읽기 전용 소스를 덮어쓰려는 시도는 이루어지지 않습니다.

Android에서 SGF를 저장하거나 다른 이름으로 저장할 때는 파일 선택과 저장 확인을 끝낸 뒤 앱을 닫으세요. 저장 성공 창은 따로 표시하지 않습니다. PPTX 내보내기는 성공 또는 실패 안내가 나올 때까지 기다리세요. 원본 파일을 덮어쓸 수 없으면 “다른 이름으로 저장”으로 다른 위치를 선택하세요.

Android는 PNG 호환 모드의 PPTX 내보내기를 지원합니다. 사용하는 프레젠테이션 소프트웨어에서 SVG 바둑판 이미지를 표시하지 못하면 설정에서 PNG로 전환하세요. SVG 이미지가 포함된 PPTX는 Microsoft 공식 PowerPoint 앱에서 열고 편집할 수 있지만 WPS에서는 SVG 이미지가 표시되지 않을 수 있습니다.

## 데이터 위치 및 사용 권장 사항

- 설정 및 KataGo 자동 성능 구성은 현재 시스템 사용자의 응용 프로그램 데이터 디렉터리에 저장됩니다.
- SGF, PPTX는 사용자 선택에 따라 저장되며 'user://'에는 자동으로 저장되지 않습니다.
- 현재 버전에는 저장되지 않은 상태 메시지와 자동 복구 메커니즘이 완전히 포함되어 있지 않습니다. 탭이나 프로그램을 닫기 전에 적극적으로 저장해야 합니다.
- 일괄적으로 가지를 자르거나, 기보 정보를 편집하거나, 많은 수의 노트를 조정하기 전에 먼저 백업 파일로 "저장"하는 것이 좋습니다.
- 소프트웨어 간 교환이 필요한 경우 다른 소프트웨어가 사용자 정의 속성을 폐기하는 것을 방지하기 위해 Gotepad의 원본 SGF 사본을 유지하는 데 우선순위를 두십시오.
