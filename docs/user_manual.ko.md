[简体中文](user_manual.md) | [English](user_manual.en.md) | [日本語](user_manual.ja.md) | [한국어](user_manual.ko.md)

## 시작하기

Gotepad를 시작한 후 빈 바둑판을 생성하거나 SGF 기보을 파일 또는 시스템 클립보드에서 로드할 수 있습니다.

### 빈 바둑판 만들기

1. 오른쪽 상단의 '새로 만들기'를 클릭하거나 'Ctrl+N'을 누르세요.
2. 9, 11, 13, 15 또는 19 바둑판 라인을 선택합니다.
3. 생성을 클릭합니다.

직접 생성된 태그에는 기본적으로 "새 노트"라는 이름이 지정됩니다. 동일한 이름을 가진 태그가 있으면 프로그램은 이름 뒤에 숫자를 추가합니다.

### 이미지에서 바둑판 만들기

Windows 버전의 경우 새 인터페이스에서 바둑판 크기를 선택하고 "로컬 사진 선택"을 클릭할 수 있습니다. Android 버전의 경우 "사진" 또는 "앨범"을 선택할 수 있습니다. 프로그램은 실제 사진, 인터넷 스크린샷 또는 책 사진에서 현재 바둑판를 식별하고 먼저 인식 및 교정 인터페이스를 표시할 수 있습니다. 세로 사진의 경우 먼저 "이미지를 시계 방향으로 회전"을 사용하여 표시 영역을 확장할 수 있습니다. 4개의 노란색 제어점을 드래그하여 바둑판의 가장 바깥쪽 4개 교차점에 정렬한 다음 "현재 4개 모서리에 따라 재식별"을 클릭합니다. 빈 지점, 검은 돌, 흰 돌 사이를 주기적으로 수정하려면 교차점을 클릭하세요. 중앙의 빨간 점은 프로그램 신뢰도가 낮은 위치를 나타내며 집중 점검을 권장합니다. 돌 마크는 아래의 실제 돌를 쉽게 확인할 수 있도록 원본 이미지의 가장자리 일부를 남겨둡니다. 확인 후 식별된 돌는 사전 배치 돌 노드로 생성되고 바둑판은 기본적으로 잠깁니다.

이미지 인식 결과는 촬영 각도, 반사, 돌 질감 및 화면 자르기에 영향을 받습니다. 생성하기 전에 네 모서리, 바둑판 크기 및 모든 빨간색 상자 위치를 확인해야 합니다. 디스크가 기본 바둑 규칙을 준수하지 않으면 프로그램은 생성을 거부하고 수정이 필요합니다.

### SGF 로드

새 인터페이스를 연 후 "로드"를 클릭하고 로컬 `.sgf` 파일을 선택할 수 있습니다. 먼저 다른 응용 프로그램에서 전체 SGF 텍스트를 복사한 다음 "붙여넣기"를 클릭하여 기보을 직접 만들 수도 있습니다. 클립보드를 통해 생성된 기보에는 연결된 소스 파일이 없으며 처음 저장할 때 선택해야 합니다.

성공적으로 로드된 후 바둑판은 첫 번째 분기의 마지막 국면으로 로밍되며 기보을 검색할 때 실수로 착수 또는 무르기를 방지하기 위해 기본적으로 잠겨 있습니다. 동일한 SGF 파일이 현재 열려 있는 경우 프로그램은 태그를 다시 생성하지 않지만 기존 태그를 활성화합니다.

Windows 배포판은 시작 매개변수에서 '.sgf' 파일 경로 수신을 지원합니다. 파일 탐색기에서 SGF의 "열기 방법"으로 Gotepad를 선택하거나 명령줄에서 SGF 경로를 `Gotepad.exe`에 전달합니다. 프로그램은 시작 후 바로 기보을 로드합니다. 여러 SGF가 동시에 전달되면 라벨이 별도로 생성됩니다.

바둑판 태그가 있는 경우 새 인터페이스의 오른쪽 상단에 있는 `✕`를 클릭하거나 `Esc`를 눌러 닫고 현재 대국로 돌아갈 수 있습니다. 현재 바둑판이 없으면 닫기 버튼이 표시되지 않으며 바둑판을 생성하거나 로드해야 합니다.

## 화면 구성

- 상단에는 기보 탭바가 있습니다. 기보로 전환하려면 라벨을 클릭하고, 닫으려면 라벨에서 `✕`를 클릭하세요. 마지막 탭을 닫으면 새 노트가 자동으로 생성됩니다.
- 왼쪽에는 바둑판 및 대국 재생 막대가 있습니다.
- 메시지 및 확인 대화 상자는 현재 창 너비에 따라 자동으로 줄바꿈되며, 작업 버튼이 화면 밖으로 확장되는 것을 방지하기 위해 너비는 창의 2/3를 초과하지 않습니다.
- 바둑판의 오른쪽에는 창 높이에 따라 자동으로 열을 변경하는 조작 버튼이 있습니다.
- 오른쪽 상단에는 설정, 새로 만들기, 저장, 다른 이름으로 저장, 내보내기, 도구가 제공됩니다. 도구 메뉴는 자주 사용되지 않는 기보 처리 기능을 중앙에 배치합니다.
- 참고사항, 기보 정보와 KataGo는 동일한 측면 패널 영역을 사용하며, 그 중 하나를 열면 다른 패널이 축소됩니다.

인터페이스는 창의 실제 수직 해상도에 따라 자동으로 크기가 조정됩니다. 창 높이가 900픽셀을 초과하지 않으면 1.0x가 사용되고, 900~2000픽셀 사이에서는 선형 확대가 사용되고, 2000픽셀에 도달하면 2.0x가 사용됩니다. 글꼴, 버튼, 아이콘, 패널 및 팝업 창이 동시에 확대됩니다. 바둑판 카메라는 인터페이스 확대로 인해 바둑판이 잘리지 않도록 남은 사용 가능한 공간을 다시 계산합니다.

데스크톱 버전은 `user://window_state.cfg`에 있는 일반 창의 위치, 크기 및 최대화된 상태를 기억하고 다음에 시작할 때 이를 복원합니다. 모니터를 변경하거나 데스크탑 레이아웃을 변경한 후 저장된 위치가 더 이상 화면의 사용 가능한 영역에 속하지 않는 경우 창이 자동으로 홈 화면 중앙으로 돌아갑니다. 모바일 버전과 웹 버전은 이 창 상태를 사용하지 않습니다.

## 바둑판 조작

### 착수

- 바둑판 잠겨 있지 않은 경우 법적 교차점에서 마우스 왼쪽 버튼을 클릭하면 됩니다.
- 사용 가능한 위치 위에 마우스를 올리면 반투명 미리보기가 표시됩니다.
- 흑백 돌 전환 버튼이나 `Ctrl+Q`를 사용하여 다음 색상을 지정합니다. 일반 착수 이후에는 기본적으로 흑백 교대가 복원됩니다.

"착수 사고 방지 터치"를 활성화한 후 합법적인 교차로를 처음 클릭하면 확인을 위해 반투명한 돌만 표시되며, 기보은 ​​즉시 수정되지 않습니다. 바둑판 오른쪽 툴바 상단의 녹색 `✓`는 착수을 확인하는 데 사용되며 빨간색 `✕`은 취소에 사용됩니다. 보류 중인 돌를 이동하려면 확인 전에 다른 법적 교차점을 클릭하고, 취소하려면 마우스 오른쪽 버튼을 클릭하세요. 기존 다음 브랜치로 진입해도 확인 없이 바로 로밍됩니다. 이 기능은 데스크톱 버전에서는 기본적으로 꺼져 있으며, 안드로이드, iOS 등 모바일 버전에서는 기본적으로 활성화되어 있습니다. 사용자가 저장한 설정은 플랫폼 기본값보다 우선합니다.
- 본 프로그램은 기본수칙을 준수하며, 자살 등 불법행위를 용인하지 않습니다.

바둑판은 반투명 그래픽으로 입력할 수 있는 모든 다음 착수 분기를 표시합니다. 현재 재생 경로의 다음 손은 사각형을 사용하고 다른 분기는 원을 사용합니다. 마커를 클릭할 때:

- 현재 선택된 색상이 기존 브랜치 착수과 동일할 경우 해당 브랜치가 입력됩니다.
- 현재 선택한 색상이 기존 브랜치 착수과 반대인 경우 동일한 위치에 선택한 색상의 새 브랜치가 생성됩니다.
- 잠금 상태에서도 상자를 클릭하면 계속해서 브랜치에 입장할 수 있으며, 새로운 착수이 생성되지 않습니다.

### 무르기, 실행 취소 및 다시 실행

- 바둑판이 잠겨 있지 않은 경우 마우스 오른쪽 버튼을 클릭하여 무르기를 요청하세요. 확인 후 현재 마지막 단계가 삭제됩니다.
- 바둑판이 잠겨 있는 경우 기보을 수정하지 않고 마우스 오른쪽 버튼을 누르면 이전 국면으로 로밍되도록 변경됩니다.
- 무르기는 기보 편집 명령이며 실행 취소와 동일하지 않습니다.
- `Ctrl+Z`는 가장 최근에 실행 취소할 수 있는 명령을 실행 취소하고 `Ctrl+R`은 다시 실행합니다. 잠금은 로밍 명령의 실행 취소/다시 실행을 방지하지 않습니다.
- 아이콘에 슬래시가 있으면 해당 실행 취소 또는 다시 실행을 현재 실행할 수 없다는 의미입니다.

### 바둑판 잠금

바둑판 잠금을 확인하거나 `Ctrl+E`를 누르면 착수 및 무르기는 금지되지만 여전히 허용됩니다.

- 재생 막대, 마우스 휠 및 화살표 키를 사용하여 대국을 탐색합니다.
- 다음 분기 표시를 클릭합니다.
- 돌 찾기 및 직접 착수이 아닌 분기 검색과 같은 기능을 사용합니다.
- 로밍 작업에 대해 실행 취소/다시 실행을 수행합니다.

잠금 바둑판은 SGF를 로드한 후 기본적으로 활성화됩니다.

## 재생 및 기보 탐색

바둑판 아래의 재생 막대는 선형 대국 경로의 현재 위치를 나타냅니다.

- 재생 막대를 드래그하거나 클릭하면 점프할 수 있습니다.
- 재생바에 마우스를 올리면 해당번호 수 번호이 표시됩니다.
- `<`, `>`를 클릭하면 한 손으로 앞이나 뒤로 탐색할 수 있습니다.
- 바둑판에 마우스를 놓으면 스크롤 휠이 위로 뒤로 이동하고 아래로 앞으로 이동합니다.
- 키보드 `←`, `→`는 전역 단일 단계 탐색 키입니다. 텍스트 상자나 목록을 편집하는 동안에는 키가 선점되지 않습니다.
- 재생 버튼을 클릭하면 설정된 간격에 따라 자동으로 진행됩니다. 중지 아이콘을 다시 클릭하거나 'Esc'를 눌러 중지하세요.
- 재생 중에 사용자가 재생 막대, 스크롤 휠, 방향 키 등을 사용하여 진행률을 변경하면 자동 재생이 중지됩니다.
- Android 버전에서는 손으로 앞으로 `>` 및 뒤로 `<`를 화면 오른쪽 하단에 있는 두 개의 큰 사각형 버튼으로 만들어 손쉬운 터치 제어가 가능합니다. 위에서 아래로, 그들은 앞뒤입니다. 재생 막대에 있는 원래의 작은 손 버튼은 여전히 ​​유지됩니다.

여러 분기가 있는 기보의 경우 재생 막대는 현재 선택된 선형 경로만 나타내며 이는 전체 기보 트리와 동일하지 않습니다.

## 분기 조작

### 본선만 남기기

오른쪽 상단 모서리에 있는 "도구"를 클릭하고 "본선 유지"를 선택하여 기보의 모든 측면 가지를 삭제하고 대국의 시작점에서 시작하여 마지막 리프 노드까지 각 레이어의 첫 번째 가지를 선택하는 경로만 유지합니다. 프로그램은 실행 전에 확인을 요청합니다. 전체 정리 작업은 명령으로 기록에 입력되므로 단 한 번의 실행 취소만으로 삭제된 모든 분기와 작업 전의 국면을 복원할 수 있습니다.

### 돌 찾기

![돌 찾기 방향으로 대국 시작 방향](../gotepad-gd/assets/ui/find_previous.svg)

![대국 방향 끝 방향 돌 찾기](../gotepad-gd/assets/ui/find_next.svg)

1. 앞으로 또는 뒤로 돌 찾기 아이콘을 클릭하거나 'Ctrl+G' 또는 'Ctrl+F'를 각각 누르십시오.
2. 불투명 돋보기 위치를 확인하기 위해 마우스를 대상 교차점 또는 돌로 이동합니다.
3. 마우스 왼쪽 버튼을 클릭하면 프로그램은 지정된 방향에서 마지막으로 위치를 변경한 국면을 검색합니다.

찾을 수 없으면 즉시 돌 찾기 모드를 종료하고 메시지를 표시합니다. 돌 찾기를 취소하려면 `Esc` 또는 마우스 오른쪽 버튼을 누르세요.

### 다음 분기 조정 또는 삭제

![브랜치 재정렬](../gotepad-gd/assets/ui/reorder_branch.svg)

이 버튼은 현재 국면에 하나 이상의 하위 분기가 있는 경우 사용할 수 있으며 'Ctrl+X'를 눌러 열 수도 있습니다. 착수 분기와 사전 배치 돌 분기가 모두 나열됩니다.

- 각 줄의 양쪽에 있는 `↑`와 `↓`를 사용하여 순서를 조정하고, 패널 상단의 녹색 `✓`을 클릭하여 결과를 작성합니다.
- 해당 브랜치의 바둑판 썸네일을 더블클릭하거나, 썸네일 오른쪽의 'Enter' 버튼을 클릭하면 해당 브랜치로 직접 로밍할 수 있습니다. 그러면 패널에 새로운 국면의 다음 분기가 표시됩니다. 진입 전에 확인되지 않은 순서 조정은 포기됩니다.
- 줄 끝의 빨간색 `✕`을 클릭하여 분기와 모든 후속 노드를 확인하고 삭제합니다.
- 패널 상단의 빨간색 `✕`을 클릭하거나 `Esc`를 눌러 커밋되지 않은 시퀀스 조정을 취소합니다.

확인된 분기 삭제는 즉시 수행되며 실행 취소를 통해 되돌릴 수 있습니다. 이후에 재정렬이 취소되는지 여부는 영향을 받지 않습니다. Undo를 통해 복원된 분기는 분기 순서의 끝으로 돌아가며 자동으로 원래 위치로 돌아가지 않습니다.

### 사전 배치 돌 분기

![사전 배치 돌 분기](../gotepad-gd/assets/ui/setup_branch.svg)

다음 단계에서 단일 착수 상자로 표현할 수 없는 사전 배치 돌개의 분기가 있는 경우 도구 모음 상단에 수량 프롬프트가 있는 버튼이 나타납니다. 클릭 후 각 브랜치로 인한 바둑판 변경 사항을 확인하고 대상 브랜치 입력을 선택할 수 있습니다.

### 분기 시각화

![분기 시각화](../gotepad-gd/assets/ui/branch_visualization.svg)

아이콘을 클릭하거나 'Ctrl+W'를 눌러 기보 트리 보기를 엽니다. 뷰에는 분기 키 노드, 메모가 있는 노드, 각 분기의 리프 노드가 포함됩니다. 큰 기보이 처음으로 생성되면 진행 상황이 표시됩니다. 생성된 썸네일은 기보 및 UID에 의해 캐시됩니다.

- 휠을 스크롤하여 보기를 확대/축소합니다.
- 마우스 오른쪽 버튼을 누른 채 캔버스를 드래그합니다.
- Android 터치 스크린 장치에서는 두 손가락을 모아서 보기를 확대하거나 축소하고, 두 손가락으로 밀어 캔버스를 이동합니다. 바둑판 썸네일이나 버튼에 닿지 않는 빈 영역에서 한 손가락으로 드래그하면 캔버스가 이동할 수도 있습니다.
- 국면을 선택하려면 썸네일을 마우스 왼쪽 버튼으로 클릭하세요.
- 확인란 왼쪽 상단에 있는 녹색 `✓`을 클릭하거나, 선택한 썸네일을 두 번 클릭하여 국면으로 이동하고 보기를 종료합니다.
- 체크박스 오른쪽 상단의 빨간색 `✕`을 클릭하고 국면 및 모든 후속 브랜치 삭제를 확인합니다.
- 오른쪽 상단에 있는 "종료"를 클릭하거나 'Esc'를 눌러 보기를 닫습니다.

첫 번째 수준 노트의 제목은 썸네일 위에 표시됩니다. 댓글이 있는 경우 제목 뒤 댓글의 첫 번째 줄을 연결하는 데 세미콜론이 사용됩니다. 제목이 비어 있으면 댓글의 첫 번째 줄만 표시됩니다. 댓글 앞에는 노트북 마커가 표시됩니다. 제목은 최대 2줄까지 표시할 수 있습니다. 한 줄이면 바둑판에 가까울 것입니다. 내용이 너무 길면 바둑판 너비로 잘립니다.

## 사전 배치 돌

재생 바 왼쪽에 있는 "사전 설정"을 클릭하거나 'Ctrl+H'를 눌러 사전 설정 모드로 들어갑니다. 입장 후 흑백 색상 전환을 제외한 일반 버튼은 일시적으로 숨겨집니다.

- 교차점을 마우스 왼쪽 버튼으로 클릭하여 현재 색상을 사전 배치 돌으로 설정합니다.
- 교차로를 지우려면 마우스 오른쪽 버튼을 클릭하세요. 오른쪽의 `⌫` 버튼을 클릭하여 지우기 상태로 들어간 다음 교차점을 클릭하여 지울 수도 있습니다.
- 사전 설정 모드는 각각 검정, 흰색, `⌫` 청소 도구를 제공합니다. 활성화할 항목을 클릭하세요. 청소 도구가 활성화되면 금색으로 표시됩니다. 'Ctrl+Q'를 눌러 흑백 간에 전환할 수도 있습니다. 착수을 사전 설정한 후에는 색상이 자동으로 변경되지 않습니다.
- 모든 수정 사항을 사전 설정 노드로 제출하려면 녹색 `✓`을 클릭합니다.
- 이 수정 사항을 취소하려면 빨간색 '✕'을 클릭하거나 'Esc'를 누르세요.

사전 설정 후 최종 디스크는 돌무리활로가 있음과 같은 기본 규칙을 계속 준수해야 합니다. 현재 국면에서 사전 설정을 허용하지 않는 경우 입구에 사용할 수 없는 상태가 표시됩니다.

## 변화도

![변화도](../gotepad-gd/assets/ui/variation.svg)

변화도 아이콘을 클릭하거나 'Ctrl+T'를 누르면 프로그램이 현재 바둑판를 임시 기보에 복사합니다. 변화도은 시도하기에 적합하며 기본 기보은 즉시 수정되지 않습니다.

- 입장 시 원래 다음 손 색상이 계승되며, 기본 색상은 흑백이 교대로 적용됩니다.
- 재생 막대 `<`, `>`를 사용하거나 바둑판에서 마우스 휠과 재생 막대를 스크롤하여 다운로드된 변경 프로세스를 탐색할 수 있습니다. 휠은 일반 대국 모드와 일치하여 위쪽으로 뒤로 이동하고 아래쪽으로 앞으로 이동합니다.
- 중간 국면으로 브라우징 시 착수으로 이어갈 수 없습니다. 먼저 변화도의 끝으로 돌아가야 합니다.
- 무르기 끝이나 중간에 허용되며, 마우스 오른쪽 버튼을 누르거나 오른쪽 `↩` 버튼을 누르면 확인 요청이 나옵니다.
- 녹색 `✓`은 새 착수을 기본 기보에 하나씩 추가한 후 종료한다는 의미입니다.
- 빨간색 `✕` 또는 `Esc`는 변경 사항을 취소하고 종료함을 의미합니다.

KataGo 후보 변화도에서 진입 시 후보 시퀀스는 자동으로 임시 기보로 채워집니다. 변화도을 종료하면 진입 전 열렸던 측면 패널이 복원됩니다.

## 국면 노트 및 바둑판 표시

![메모](../gotepad-gd/assets/ui/notes.svg)

메모 아이콘을 클릭하거나 'Ctrl+M'을 눌러 메모 패널을 엽니다. 동일한 국면에는 여러 개의 메모 레이어가 있을 수 있습니다.

- '+'를 클릭하면 0부터 시작하는 번호가 매겨진 메모 레이어를 추가할 수 있습니다.
- 중간 번호가 잘못 정렬되는 것을 방지하기 위해 가장 높은 번호가 있는 노트의 마지막 레이어만 닫을 수 있습니다.
- 음 번호 0은 현재 착수 또는 사전 설정 노드에 저장됩니다. 후속 노트는 SGF의 독립 노드에 저장됩니다.

각 수준의 참고 사항에는 노드 제목, 설명, 바둑판 표시 및 수 번호 메서드가 포함됩니다. 제목이나 댓글이 변경되면 옆에 있는 녹색 `✓`을 사용하여 수락하거나 빨간색 `✕`을 사용하여 삭제합니다. 편집 중에 `Esc`를 누르면 편집이 취소되고 입력 포커스가 해제됩니다. 확인되지 않은 내용이 있는 다른 컨트롤을 클릭하면 프로그램에서 해당 컨트롤을 유지할지 여부를 묻습니다.

수 번호 옵션 오른쪽에 있는 "포커스"를 선택하면 기보 노트 전체의 미리보기 모드로 진입할 수 있습니다. 미리보기 페이지는 PPTX에서 내보낸 기보 트리 순서대로 배열되어 있으며, 동일한 국면의 다층 노트가 태그 번호에 따라 순서대로 표시됩니다. 현재 국면에 음표가 있을 경우 선택한 음표부터 시작하며 음표가 없을 경우 가장 가까운 음표에 먼저 배치되고 뒤가 없을 경우 앞쪽에 배치됩니다. 미리보기 중에 바둑판 아래의 재생 막대는 음표 사이를 이동하는 데 사용되며 `<`, `>`는 단일 단계에서 페이지를 변경하는 데 사용되며 재생 버튼은 설정의 재생 간격에 따라 자동으로 페이지를 변경합니다. Android 버전의 오른쪽 하단에 있는 큰 페이지 변경 버튼도 계속 사용할 수 있습니다. 노트 패널은 완전한 편집 기능을 유지합니다. 상단의 라벨은 현재 노트 레이어를 나타내는 데에만 사용됩니다. 재생 컨트롤은 페이지 변경에 균일하게 사용됩니다. "포커스" 버튼은 "종료"로 변경되며 클릭 후 일반 노트 모드로 돌아갑니다. 기보에 메모가 없으면 미리보기에 들어갈 수 없습니다.

안드로이드 버전에서는 노트 제목과 댓글 편집 영역에 '전체 선택, 복사, 잘라내기, 붙여넣기' 터치 버튼을 제공합니다. 먼저 텍스트 상자에 커서를 놓거나 텍스트의 일부를 선택한 다음 해당 버튼을 클릭하여 Android 시스템 클립보드와 텍스트를 교환합니다. Windows와 같은 데스크톱 버전은 시스템 바로 가기 키와 마우스 오른쪽 버튼 클릭 메뉴를 계속 사용하며 이 버튼 행을 표시하지 않습니다.

전체 기보 메모를 제거해야 하는 경우 오른쪽 상단 모서리에 있는 "도구"를 클릭하고 "메모 지우기"를 선택할 수 있습니다. 확인 후 국면 제목, 댓글, 수 번호 방법 및 바둑판 표시가 모두 삭제됩니다. 전체 작업은 하나의 기록 단계만 수행하며 실행 취소를 통해 완전히 복원할 수 있습니다.

### 바둑판 표시

- `ABC` : A-Z, a-z 순으로 문자 표시를 추가합니다.
- `TR`: 삼각형 표시.
- `SQ`: 상자 표시.
- `CR`: 원 표시.
- `MA`: 십자 표시.
- 휴지통: 표시를 지웁니다.

표시 모드로 들어간 후 다른 인터페이스는 일시적으로 숨겨집니다. 왼쪽 클릭은 빈 교차점 또는 돌에 표시를 추가하거나 전환할 수 있습니다. 제출하려면 오른쪽에 있는 녹색 `✓`을 사용하고, 포기하려면 빨간색 `✕` 또는 `Esc`를 사용하세요. 검은 돌의 표시에는 밝은 색상을 사용하고, 흰색 돌과 빈 돌의 교차 부분에는 어두운 색상을 사용합니다.

### 수 번호

번호 매기기 방법은 주로 PPTX 조판에 사용됩니다.

- **분기 상대 번호 매기기**: 이전 레이아웃 개체 노드 이후 1부터 번호를 다시 매깁니다.
- **분기 절대 번호 매기기**: 이전 레이아웃 개체 노드의 착수만 현재 국면으로 표시하지만 번호 매기기에서는 현재 분기의 해당 착수 중 실제 수 번호을 사용합니다.
- **Global Absolute Numbering**: 대국의 시작점부터 현재 경로의 모든 착수에 대해 실제 수 번호을 사용합니다.
- **번호 없음**: 내보낸 바둑판은 수 번호을 표시하지 않습니다.

동일한 교차점에 착수이 여러 개 있는 경우 내보내기에는 가장 작은 숫자가 먼저 표시되고 이 숫자와 바둑판 아래 후속 숫자 간의 대응 관계가 설명됩니다.

메모 패널이 열려 있고 현재 국면에 메모가 있는 경우 현재 메모 탭에서 선택한 번호 매기기 방법에 따라 바둑판이 표시되도록 우선순위가 부여되며, 설정 패널의 일반 수 번호 표시 옵션을 일시적으로 무시합니다. 메모 태그를 전환하거나 메모를 사용하여 다른 국면으로 로밍한 후 동시에 업데이트됩니다. 현재 국면에 메모가 없고 `+` 태그만 표시되면 일반 설정이 사용됩니다. 노트 패널을 닫은 후에도 일반 설정이 복원됩니다.

## 기보 정보

![기보정보](../gotepad-gd/assets/ui/sgf_info.svg)

기보 정보 패널에서는 대국 이름, 이벤트, 라운드, 날짜, 위치, 흑백 이름 및 단급, 결과, 규칙, 덤, 접바둑 돌 수 번호, 시간, 카운트다운, 레이아웃 이름, 레코더, 소스, 저작권 및 대국 일반 등급 및 기타 일반적으로 사용되는 SGF 헤더 정보를 편집할 수 있습니다.

수정 후 패널 상단의 녹색 `✓`을 클릭하면 모든 필드를 한꺼번에 제출할 수 있고, 빨간색 `✕`을 클릭하면 포기할 수 있습니다. 편집 내용이 초점을 잃으면 유지할지 여부도 묻습니다. 날짜, 덤, 접바둑 돌 수 번호, 시간 및 결과와 같은 필드는 인터페이스 예시 형식을 따라야 합니다. 그렇지 않으면 저장할 때 SGF 유효성 검사기에 의해 거부될 수 있습니다.

## SGF 저장 및 불러오기

- "저장"을 클릭하거나 `Ctrl+S`를 누르고 경로를 확인한 후 현재 기보을 저장합니다.
- "저장"을 클릭하거나 `Ctrl+A`를 눌러 새 파일을 선택합니다.
- 성공적인 저장 프롬프트는 공백, Enter 또는 `Esc`로 닫을 수 있습니다.
- 현재 태그를 닫으면 닫혔는지 여부만 확인되며 아직 완전한 '저장되지 않은 수정 사항' 상태 감지가 구현되지 않았습니다. 적극적으로 저축하는 습관을 길러주세요.

이 프로그램은 KataGo 파일을 로드, 저장, 내보내기 또는 선택할 때 하나의 파일 선택기만 허용합니다. 기본 파일 선택기가 Gotepad의 기본 창에 의해 가려진 경우 해당 파일 선택 버튼을 다시 클릭하면 두 번째 선택기를 생성하지 않고 이미 열려 있는 선택기를 다시 전경으로 가져옵니다.

Gotepad는 경로 번호, 법적 파일, 지점, AB/AW/AE 사전 설정 작업, 제목, 설명, 공통 태그 및 기본 비밀번호 정보를 읽고 씁니다. 이 프로그램은 또한 형식 버전, 국면 UID 및 메모 번호 매기기 방법을 저장하는 데 사용되는 `AP[Gotepad:Version]`, `GP`, `XU` 및 `XN`과 같은 Gotepad 사용자 정의 속성을 작성합니다.

SGF를 저장할 때 Gotepad는 쓰기 실패 및 원본 파일 손상을 방지하기 위해 보호 조치를 취합니다. 중요 기보 독립적인 백업을 생성하려면 정기적으로 "다른 이름으로 저장"을 사용하는 것이 좋습니다.

참고:

- Gotepad 사용자 정의 속성을 임의로 수정하기 위해 텍스트 편집기를 사용하는 것은 권장되지 않습니다. 그렇지 않으면 UID 충돌이나 유형 오류로 인해 다시 로드가 실패할 수 있습니다.
- Gotepad에서 생성되지 않은 SGF의 경우 프로그램은 이러한 사용자 정의 속성을 맹목적으로 신뢰하지 않지만 범위를 충족하지 않는 값을 확인하거나 무시합니다.
- 불법 착수은 가져올 수 없습니다. SGF의 패스는 바둑판 상태 노드로 관리되지 않지만 저장 시 기보에서 요구하는 대로 생성됩니다.
- 외부 SGF 소프트웨어는 다층 음표 번호와 같은 Gotepad의 사용자 정의 데이터를 완전히 유지하지 못할 수 있습니다. 소프트웨어 간에 교환하기 전에 원본 파일을 보관하는 것이 좋습니다.

## 업데이트 확인

화면 맨 오른쪽의 **도구** 아래에 있는 **업데이트**를 누르면 GitHub에 연결하여 현재 플랫폼에 적용되는 새 버전을 확인합니다. 확인이 끝나면 현재 버전, 업데이트 가능한 최신 버전, 그리고 해당 범위에서 최대 5개 적용 대상 버전의 업데이트 내용이 최신 버전부터 이전 버전 순서로 표시됩니다. 과거 버전에 별도의 GitHub Release가 없으면 해당 Tag의 버전 커밋 설명을 사용합니다. 다른 플랫폼 접두사가 붙은 릴리스는 무시됩니다. 현재 버전이 이미 최신이고 해당 GitHub Release가 남아 있으면 그 버전의 업데이트 내용도 표시됩니다.

오른쪽 위에서 **GitHub** 또는 **클라우드 드라이브**를 선택한 다음 **업데이트**를 누르면 시스템 기본 브라우저에서 해당 다운로드 페이지가 열립니다. Gotepad는 업데이트 확인과 페이지 열기만 수행하며 앱 안에서 업데이트를 다운로드하거나 설치하지 않습니다. GitHub에 연결할 수 없는 경우에도 결과 창에 오류가 표시되며 클라우드 드라이브 링크는 계속 사용할 수 있습니다.

## PPTX 내보내기

오른쪽 상단에 있는 "내보내기"를 클릭하고 '.pptx'를 선택하여 위치를 저장하세요. B5 가로 템플릿을 사용하여 내보내면 다음 콘텐츠가 레이아웃 페이지가 됩니다.

- 메모가 포함된 모든 국면;
- 동일한 국면의 각 메모 레이어;
- 메모가 없더라도 모든 가지 리프 노드를 강제로 내보냅니다.

바둑판은 흑백 출판 스타일을 사용하고 수 번호로 지정된 메모, 연속 문자 및 TR/SQ/CR/MA 그래픽 표시를 그립니다. 반복되는 착수 번호의 제목, 설명, 그림 제목 및 설명이 레이아웃에 기록됩니다.

설정의 "바둑판 좌표 내보내기(왼쪽 및 위쪽)"는 내보낸 바둑판에 좌표가 있는지 여부를 제어할 수 있습니다. 활성화한 후에는 바둑판의 위쪽에 열 문자만 그려지고 왼쪽에는 행 번호가 그려집니다. 좌표는 바둑판에 가깝고 추가 공간 점유를 최소화하기 위해 가장자리 돌를 피합니다. 이 옵션은 기본적으로 꺼져 있으며 SVG 및 PNG 내보내기에 모두 적용됩니다.

### SVG 또는 PNG

"설정 → PPTX 바둑판 그림"에서 형식을 선택합니다.

| 형식 | 장점 | 메모 |
|---|---|---|
| SVG(기본값) | 벡터는 선명하고, 확대 및 인쇄 품질이 가장 좋으며, 일반적으로 파일 크기가 더 작습니다 | 일부 이전 버전의 PowerPoint, WPS 또는 호환 소프트웨어는 내장된 SVG를 표시하지 않을 수 있습니다 |
| PNG | 다양한 프레젠테이션 소프트웨어에서 안정적으로 표시 가능 | 바둑판은 1600×1600픽셀로 생성되며 일반적으로 파일이 더 크고 극단적인 확대도 SVG |

내보낸 파일이 새 버전의 PowerPoint에서 주로 사용되거나 고품질 인쇄에 사용되는 경우 SVG에 우선순위를 부여하세요. 알 수 없는 환경의 사용자에게 전송해야 하거나 바둑판 이미지가 표시되지 않는 문제가 발생한 경우 PNG를 선택하세요.

### 글꼴

PPTX의 바둑판 번호는 PNG 모드에서 래스터화되었지만 제목과 설명은 여전히 편집 가능한 텍스트입니다. 현재 내보낸 파일에는 글꼴이 포함되어 있지 않습니다. 편집 또는 인쇄 컴퓨터의 프로젝트에 포함된 Noto Sans CJK SC 및 Noto Serif CJK SC 글꼴을 설치하는 것이 좋습니다.

글꼴이 설치되어 있지 않으면 PowerPoint에서 해당 글꼴을 대체하므로 줄바꿈이나 레이아웃 변경이 발생할 수 있습니다.

## KataGo 분석

![KataGo 분석](../gotepad-gd/assets/ui/katago.svg)

Gotepad의 데스크톱 버전은 소프트웨어와 함께 KataGo 실행 파일 및 신경망 모델을 배포하지 않습니다. 사용하기 전에 설정에서 지정해야 합니다:

1. KataGo 분석 엔진 실행 파일
2. 이 버전과 호환되는 신경망 모델(보통 `.bin.gz`)
3. 분석 엔진에서 사용하는 `.cfg` 구성 파일.

설정이 완료되면 "테스트 경로"를 클릭하세요. 또한 "자동 성능 감지"를 실행하여 프로그램이 검색 스레드 수와 배치 크기를 추정하도록 할 수도 있습니다. TensorRT와 같은 백엔드의 첫 번째 초기화에는 시간이 오래 걸릴 수 있으며 감지에는 고정된 시간 제한이 설정되지 않습니다. 현재 창의 약 80%를 차지하는 모달 창에서 자동 줄 바꿈의 실시간 출력을 확인하고 적극적으로 중지할 수 있습니다. 테스트가 성공한 후 결과 창을 닫고 설정 패널 왼쪽 상단에 있는 녹색 '✓'를 사용하여 테스트 결과 저장을 확인하세요. 테스트 중에는 다른 설정이 일시적으로 비활성화됩니다.

### 현재 국면 분석

KataGo 패널을 연 후:

- 재생 버튼을 누르면 현재 국면 분석이 시작되며, 설정된 새로 고침 간격에 따라 결과가 업데이트됩니다.
- 일시 중지 버튼은 인터페이스 새로 고침만 일시 중지하고 KataGo는 계속 계산합니다. 재개하면 최신 결과가 표시됩니다.
- 중지 버튼은 현재 분석을 종료하라는 요청을 엔진에 보냅니다.
- "계산량 증가"는 오른쪽 입력란에 지정된 `maxplayouts`에 따라 현재 국면을 재분석합니다. 값은 0보다 커야 합니다. 작동 중에 인터페이스 새로 고침을 일시 중지하거나 분석을 중지할 수 있습니다.
- "연속 분석"을 확인한 후 새로운 국면으로 로밍하면 자동으로 다시 분석됩니다. 이때 재생, 일시 정지 및 정지 버튼은 연속 모드로 대체됩니다.

후보 테이블에는 현재 착수 입구 승률, 집 차이 및 변화도의 위치가 표시됩니다. 상위 3개 후보는 바둑판에 반투명 짙은 녹색, 연한 녹색 및 노란색으로 표시됩니다. 설정의 "추가 디스크 후보 수"는 0~99개 이상의 후보를 표시할 수 있습니다. 추가 후보는 돌 관찰에 미치는 영향을 줄이기 위해 투명도 20%의 연한 노란색을 균일하게 사용합니다. 후보 위치가 기보의 현재 플레이 경로를 따라 실제 다음 이동과 일치하는 경우 얇은 검정색 프레임이 후보에 추가되며 추가 후보가 히트할 때에도 동일한 내용이 표시됩니다. 전체 플레이 경로를 분석했을 때 기보의 실제 다음 이동이 상위 3개에 속하지 않고 분석된 착수 사각형 승률이 첫 번째 선택보다 최소 10% 포인트 낮은 경우 프로그램은 실제 다음 이동 위치에 연한 빨간색 원과 함께 마이너스 승률 차이를 표시합니다. 테이블에서 "Enter"를 클릭하면 후보 시퀀스가 ​​변화도에 로드됩니다. 바둑판이 잠겨 있으면 디스크의 후보 표시를 직접 클릭하여 해당 변화도을 입력한 다음 유지하거나 폐기하도록 선택할 수도 있습니다.

### 전체 재생 경로 분석

"전체 재생 경로 분석"을 클릭하면 프로그램은 "계산량"을 사용하여 승률 및 집 차이 곡선을 하나씩 생성합니다. 이 값은 기본적으로 낮으며 추세를 빠르게 관찰하기 위한 것이므로 정확한 연구 결론으로 ​​받아들여서는 안 됩니다. 곡선의 수직선은 현재 국면을 나타냅니다. 그곳으로 이동하려면 곡선의 다른 곳을 클릭하세요.

KataGo의 승률 및 집 차이은 규칙, 덤, 모델, 계산량 및 하드웨어의 영향을 받습니다. 방문 횟수가 적으면 결과가 크게 변동하므로 중요한 결론은 더 많은 계산을 통해 검토해야 합니다. 데스크톱 버전은 사용자가 구성한 외부 KataGo 엔진을 사용합니다. Android 버전은 장치에서 제공하는 OpenCL GPU 백엔드 사용에 우선 순위를 부여하고 장치가 OpenCL을 지원하지 않거나 백엔드가 시작되지 않는 경우 더 호환되는 Eigen CPU 백엔드로 자동 전환합니다. iOS 버전은 여전히 ​​로컬 KataGo를 실행하지 않습니다.

### 인간 모방 대국

![인간 모방 대국](../gotepad-gd/assets/ui/katago_human_play.svg)

현재 바둑판에서 Human SL 모델 대국로 시작하려면 일반 KataGo 아이콘 아래에 있는 인간 모방 대국 아이콘을 클릭하세요. 시작하기 전에 AI가 흑백, 현대 또는 AlphaGo 이전 기풍을 재생하는지, 기력를 시뮬레이션하는지, 손당 AI 계산 금액을 선택할 수 있습니다. 계산량 입력 상자에는 "인간 모방 대국 계산량" 설정의 현재 방문 값이 표시되며 대화 상자의 임시 조정은 이 대국에만 적용됩니다. 값이 낮을수록 더 빠르지만 마스터 모델이 평가할 인간 후보가 적어서 중대한 실수가 발생할 가능성이 더 높습니다. 값을 높이면 선택된 인간을 계속 유지하면서 과도한 손실을 입은 후보자를 더 완전히 억제합니다. 프로그램은 현재 바둑판를 유지하므로 이미 기보이 있는 중간 국면을 AI에 넘겨 인수할 수 있습니다.

인간 모방 대국 모드에 들어가면 KataGo 분석 패널이 자동으로 열립니다. 인간 모방 대국는 임시 기보을 사용하고 진행률 표시줄과 일반 바둑판 도구는 일시적으로 숨겨지며 KataGo 분석, 종국 계가, 무르기, 유지 및 포기 버튼만 유지됩니다. 현재 국면 연산, 후보 테이블, 분석 패널 오른쪽 하단에 있는 전체 기보 빠른 분석 버튼은 모두 작동 불가능하지만, 승률, 집 차이 곡선은 대국 결과로 계속 업데이트됩니다. 인간 라운드에서는 무르기 버튼을 사용하여 이전 인간 착수과 후속 AI 동작을 한 번에 취소할 수 있습니다. AI는 사고 기간 동안 무르기를 할 수 없습니다. 모드 종료 후 분석 패널은 진입 전의 열림 또는 닫힘 상태로 돌아갑니다.

분석 패널의 상태 메시지에는 현재 휴먼 SL 장비 앞에 '[랭크_1d] AI가 생각하고 있습니다...'와 같이 앞에 붙습니다. `rank_'는 현대의 기풍을 나타내고, `preaz_`는 알파고가 등장하기 전의 기풍을 나타내며, 후반부는 이 게임이 선택한 기력를 나타낸다.

AI가 패스을 선택하면 프로그램은 사용자에게 패스도 선택할지 여부를 묻고 독립적인 패스 버튼을 제공하지 않습니다. 착수을 계속하기로 선택한 후에도 바둑판에서 계속 바둑을 두기할 수 있습니다. 양 당사자는 종국 계가를 사용하여 패스 이후의 결과를 확인할 수 있습니다. 녹색 `✓`을 클릭하면 프로그램은 이 작업이 대국를 종료하고 대국 프로세스를 원래 기보에 단계별로 기록하고 확인 후 실행한다는 메시지를 표시합니다. 빨간색 '✕' 또는 'Esc'는 확인 후 이 대국 레코드를 삭제합니다.

### 종국 계가

![종국 계가](../gotepad-gd/assets/ui/territory_scoring.svg)

종국 계가는 현재 중국어 규칙만 지원합니다. 사용하기 전에 공배를 모두 완료한 다음 바둑판 오른쪽 도구 모음 끝에 있는 종국 계가 아이콘을 클릭합니다. 프로그램은 KataGo를 호출하여 각 교차점의 흑백을 결정하고 바둑판을 반투명 영역 마커로 덮습니다. 녹색 `✓`, 빨간색 `✕`. 오른쪽의 독립 로그 패널에는 엔진 시동 정보와 실시간 판단 진행 상황이 명령줄처럼 한 줄씩 표시됩니다.

KataGo의 생사, 지역 판단이 틀릴 수도 있습니다. 오류가 발견되면 해당 교차점을 클릭하면 연결된 전체 영역이 네 방향으로 반대쪽으로 전환됩니다. 모든 표시를 확인한 후 녹색 `✓`을 클릭하면 프로그램이 사망으로 판단되는 돌를 제거하고 남은 빈 포인트에 대해 지역 구분을 수행하며 "돌 + 빈 포인트"의 중국 규칙에 따라 전체 흑백, 덤 및 승패 번호를 나열합니다. 빨간색 `✕` 또는 `Esc`는 기보을 수정하지 않고 바로 종료됩니다. 종국 계가 결과는 보조 확인용으로만 사용됩니다. 복잡한 삶과 죽음, 빅과 미완성 공배는 여전히 사용자의 검토를 받아야 합니다.

## 설정

오른쪽 상단의 '설정'을 클릭하거나 'Ctrl+O'를 누르세요. 설정을 수정한 후 패널의 왼쪽 상단 모서리가 나타납니다. 저장하려면 녹색 `✓`, 원래 수정 사항을 복원하려면 파란색 `↺`, 취소하고 닫으려면 빨간색 `✕`을 선택하세요.

### 인터페이스 언어

"인터페이스 언어"는 중국어, 일본어, 한국어, 영어 중에서 선택할 수 있습니다. 옵션을 전환하면 인터페이스에서 선택한 언어를 즉시 미리 볼 수 있습니다. 녹색 `✓`을 클릭하여 설정을 기록하고 다음 시작 시 계속 사용합니다. 파란색 `↺`, 빨간색 `✕`을 클릭하거나 설정 패널을 직접 닫아 설정이 열렸을 때 언어를 복원하세요. '[GNE...]'로 번호가 매겨진 프로그램 버튼, 프롬프트, 도구 설명 및 핵심 명령 메시지는 언어에 따라 전환됩니다. 기보 제목, 메모, 파일 이름, KataGo 원시 로그 및 SGF 파일 자체의 내용은 자동으로 번역되지 않습니다. 데스크탑 시스템에서 제공하는 기본 파일 선택기는 운영 체제 언어를 사용하며 Gotepad의 인터페이스 언어로 제어되지 않습니다.

### 외관 및 재생

- 바둑판 질감: 밝은 나뭇결과 어두운 나뭇결을 전환합니다.
- 돌 질감: 광택 또는 무광택 흑백 돌로 전환합니다.
- 화면 왼쪽 및 오른쪽 여백(모바일의 경우): 픽셀 단위로 바둑판, 탭 막대, 버튼 및 패널을 화면 왼쪽 및 오른쪽 가장자리에서 동시에 멀리 유지하고 대칭으로 적용합니다. 기본값은 '0px'입니다. 둥근 모서리나 컷아웃이 있는 가로 방향 장치에서는 컨트롤이 완전히 표시될 때까지 이 값을 점진적으로 늘릴 수 있습니다. 배경 텍스처는 여전히 전체 화면을 채웁니다.
- 바둑판 가로 너비 비율: 원래 사용 가능한 가로 공간의 최대 비율을 사용하도록 바둑판을 제한합니다. 허용 범위는 '50%~100%'이며, 기본값은 '100%'입니다. '4:3'과 같이 수평 공간이 좁은 화면에서는 적절하게 조정하여 메모와 KataGo 분석 패널을 위한 더 많은 공간을 확보할 수 있습니다. 바둑판은 가장자리가 잘리지 않고 완전히 표시됩니다.
- 대형 UI(모바일 단말기용): 활성화되면 창 높이와 선형으로 계산된 현재 인터페이스 배율에 오른쪽에 지정된 배율이 곱해집니다. 기본값은 '1.5'배로 휴대폰이나 태블릿에서의 터치 조작에 편리합니다. 허용되는 설정 범위는 '0.7~2.0'이며, 범위를 벗어나는 값은 적용되지 않습니다. 이 옵션은 데스크탑에서도 나타나고 사용할 수 있습니다.
- 수 번호 표시: 최신 1랏, 10개 손, 전체 수 번호 또는 맞춤 수량을 표시합니다.
- 절대 수 번호: 현재 분기의 절대 착수수 번호을 사용하고, 그렇지 않으면 상대 번호를 표시합니다.
- 재생 간격: 자동 재생의 각 단계를 기다리는 시간(초), 기본값은 1초입니다.
- 착수 사운드 효과: 0-100 슬라이더를 사용하여 조정합니다. 기본값은 50이며, 0으로 설정하면 음소거됩니다. 프로그램은 5개의 실제 바둑착수 녹음을 무작위로 재생합니다. 새로운 착수이 성공적으로 생성되어 다음 착수 노드로 로밍되면 재생됩니다. 기보 로드, 사전 설정된 노드로 로밍 및 사전 배치 돌이 트리거되지 않습니다.
- 착수 실수 방지 터치: 먼저 확인을 위해 반투명 돌를 표시하고 녹색 `✓`을 클릭하여 실제로 착수을 클릭합니다. 데스크탑에서는 기본적으로 꺼져 있고 모바일 터미널에서는 기본적으로 활성화되어 있습니다.
- PPTX 바둑판 이미지: SVG와 PNG 간 전환, 기본값은 SVG입니다.
- 바둑판 좌표 내보내기: PPTX 바둑판 위쪽에 열 문자를 표시하고 왼쪽에 행 번호를 표시합니다. 기본값은 꺼져 있습니다.

### KataGo

- 분석 계산량 : 현재 국면으로 분석된 'maxVisits', 기본값은 500입니다.
- 분석 새로 고침 간격: 단계별 결과를 수신하는 간격이며 기본값은 2초입니다.
- 후보 변화도수 번호: 표시되는 후보 PV의 최대 개수는 수 번호이며, 기본값은 10입니다.
- 추가 보드 후보 수: 상위 3개 후보 외에 표시되는 보드 후보 수로, 범위는 0~99이며, 기본값은 0입니다.
- Display 집 차이: 후보 테이블과 곡선이 집 차이을 표시할지 여부를 제어합니다.
- 전체 기보 빠른 분석 계산량 : 국면 이용 방문수를 하나씩 분석하며, 기본 1, 속도를 우선으로 합니다.
- 테스트 경로: 실행 파일, 모델 및 구성을 시작할 수 있는지 확인합니다.
- 자동 성능 감지: KataGo가 감지를 완료하거나 사용자가 현재 장치의 적절한 매개변수를 추정하기 위해 적극적으로 중지할 때까지 계속 실행합니다. 벤치마크 출력은 실행 중에 모달 창에 표시됩니다.

설정을 열 때 저장된 KataGo 경로가 유효하지 않게 되면 인터페이스에서 경로가 지워지고 다시 선택해야 합니다. 자동으로 생성된 성능 구성은 Godot의 사용자 데이터 디렉터리에 저장되며 Windows, Linux 및 macOS의 권한 차이를 수용하기 위해 설치 디렉터리에 기록되지 않습니다.

"KataGo 인간 모방 대국"은 독립된 설정 영역입니다. 데스크탑 버전은 현재 KataGo 실행 파일과 호환되는 Human SL '.bin.gz' 모델을 선택해야 합니다. Android 버전은 시스템 파일 선택기를 통해 모델을 가져오고 가져온 파일은 애플리케이션에서 관리됩니다. Human SL 모델은 일반 분석 모델로 대체할 수 없습니다. 여기서 "인간 모방 대국 계산량"은 새로운 대국의 기본 방문일 뿐만 아니라 자동 성능 감지에 사용되는 실제 부하입니다. 수정 후에는 이 영역에 대한 성능 감지를 다시 수행해야 합니다. 이 감지는 인간 모방 대국에 대한 별도의 구성을 생성하며 일반 분석 모델의 감지 결과는 직접 재사용되지 않습니다.

인간 모방 대국 성능 테스트를 시작하면 프로그램은 먼저 설정 패널에서 모델 경로를 확인합니다. 경로가 저장되지 않았거나 현재 유효한 경로와 다른 경우 프로그램은 경로를 먼저 저장하고 계속할지 묻습니다. 확인 후 파일이 실제로 존재하는지, 읽을 수 있는지, 형식이 지원되는지 여부도 확인합니다. 확인에 실패하면 유효한 모델을 다시 선택해야 합니다. 여기서 확인은 선택한 모델 경로를 적용하는 역할만 담당합니다. 성능 테스트가 성공한 후에도 새로 생성된 성능 구성을 저장하려면 설정 패널의 왼쪽 상단에 있는 녹색 `✓`을 클릭해야 합니다.

제목, 댓글 등 텍스트 입력란에 포커스가 있을 경우 단축키가 실행되지 않습니다. 텍스트 편집을 종료하거나 취소하려면 먼저 `Esc`를 누른 다음 전역 단축키를 사용하세요. Gotepad에서 `Ctrl+A`와 `Ctrl+W`는 각각 "다른 이름으로 저장" 및 "분기 시각화"로, 이는 일부 일반적인 소프트웨어의 기본 의미와 다릅니다.

## Android 버전

현재 Android 버전은 Android 9 이상이 설치된 arm64-v8a 기기를 지원하며 가로 방향 사용을 위해 설계되었습니다. APK 파일을 기기에 복사하여 설치하세요. 시스템이 설치를 차단하는 경우 시스템 메시지에 따라 해당 소스에서 애플리케이션을 설치할 수 있도록 허용해야 합니다.

Android 버전에는 실행 파일이나 구성 경로를 선택할 필요 없이 KataGo OpenCL/Eigen 분석 백엔드, 모델 및 내부 관리 구성 파일이 내장되어 있습니다. 현재 APK에 내장된 모델은 'g170e-b10c128-s1141046784-d204142634'이며 KataGo g170 확장 학습의 10블록/128채널 네트워크에 속합니다. g170 훈련 배치에 컴퓨팅 성능과 데이터를 제공하고 관련 모델 데이터를 CC0에 따라 공개 도메인에 제공한 Jane Street 및 KataGo 작성자 David J. Wu(lightVector)에게 감사드립니다. 또한 모델의 다운로드 이미지를 제공한 pachi 프로젝트에도 감사드립니다. 설정의 "신경망 모델"은 기본적으로 내장 모델을 사용합니다. "찾아보기"를 클릭하여 Android 시스템 파일 선택기를 통해 표준 KataGo `.bin.gz` 또는 `.txt.gz` 가중치를 가져올 수도 있습니다. 가져오기 프로세스는 모델을 Gotepad의 애플리케이션 데이터 디렉토리에 복사하므로 원본 파일의 후속 이동 또는 삭제는 사용에 영향을 미치지 않습니다. 대형 모델을 가져오기 전에 장치에 충분한 저장 공간과 실행 메모리가 있는지 확인하세요. BadukAI와 같은 소프트웨어에서 사용되는 이중 파일 Android 최적화 모델은 표준 KataGo 가중치가 아니므로 여기에 직접 로드할 수 없습니다. 소프트웨어와 함께 제공된 모델로 다시 전환하려면 "내장"을 클릭하고 녹색 `✓`으로 저장하세요. 프로그램은 장치에 의해 노출된 OpenCL GPU 백엔드 사용에 우선순위를 부여합니다. 장치에 사용 가능한 OpenCL 구현이 없거나, 드라이버 초기화가 실패하거나, 독립 분석 프로세스가 비정상적으로 종료되는 경우 자동으로 Eigen CPU 백엔드로 대체됩니다. 분석 계산량, 새로 고침 간격, 후보 변화도수 번호, 집 차이 표시 및 전체 기보 빠른 분석 계산량과 같은 옵션은 계속 조정할 수 있으며 자동 성능 감지도 실행할 수 있습니다. 감지 결과는 내부 구성에 기록되기 전에 설정 패널의 왼쪽 상단에 있는 녹색 `✓`으로 확인되어야 합니다. OpenCL 백엔드는 처음 실행하거나 모델을 변경할 때 현재 GPU에 맞게 조정해야 하므로 후속 출시보다 속도가 상당히 느려질 수 있습니다. 분석하면 전력 소비와 발열이 증가합니다. 장시간 분석 시에는 기기 온도에 주의하는 것이 좋습니다.

Android 버전은 시스템 파일 선택기를 통해 SGF를 로드하거나 시스템 클립보드에서 전체 SGF 텍스트를 붙여넣을 수 있습니다. 중국어, 일본어, 한국어 등의 파일명과 기보 내용을 정상적으로 표시할 수 있습니다.

"다음으로 열기" 시스템을 지원하는 Android 파일 관리자 또는 기타 애플리케이션은 Gotepad를 사용하여 SGF를 직접 열 수 있습니다. 애플리케이션이 실행되고 있지 않으면 시작되어 기보이 로드됩니다. 애플리케이션이 이미 실행 중이면 새 탭에서 열립니다. 이미 열려 있는 동일한 기보이 기존 탭으로 전환됩니다. 외부 애플리케이션에서 제공하는 파일에는 읽기 권한만 있을 수 있습니다. 이 경우 도구 모음의 "저장"은 저장할 새 위치를 선택하도록 자동으로 변경되며 읽기 전용 소스를 덮어쓰려는 시도는 이루어지지 않습니다.

저장하거나 SGF로 저장하거나 Android에서 PPTX를 내보낼 때 프로그램을 닫기 전에 성공 또는 실패 메시지가 나타날 때까지 기다리십시오. 원본 파일을 직접 덮어쓸 수 없는 경우 "다른 이름으로 저장"을 사용하여 다른 위치를 선택하세요.

Android 측은 현재 PNG 모드에서 PPTX 내보내기를 지원하지 않습니다. 설정에서 SVG 모드를 선택하세요. PPTX의 SVG 이미지 버전은 Microsoft의 공식 PowerPoint 앱을 사용하여 보고 편집할 수 있습니다. WPS는 SVG 이미지를 표시하지 못할 수도 있습니다.

## 데이터 위치 및 사용 권장 사항

- 설정 및 KataGo 자동 성능 구성은 현재 시스템 사용자의 응용 프로그램 데이터 디렉터리에 저장됩니다.
- SGF, PPTX는 사용자 선택에 따라 저장되며 'user://'에는 자동으로 저장되지 않습니다.
- 현재 버전에는 저장되지 않은 상태 메시지와 자동 복구 메커니즘이 완전히 포함되어 있지 않습니다. 탭이나 프로그램을 닫기 전에 적극적으로 저장해야 합니다.
- 일괄적으로 가지를 자르거나, 기보 정보를 편집하거나, 많은 수의 노트를 조정하기 전에 먼저 백업 파일로 "저장"하는 것이 좋습니다.
- 소프트웨어 간 교환이 필요한 경우 다른 소프트웨어가 사용자 정의 속성을 폐기하는 것을 방지하기 위해 Gotepad의 원본 SGF 사본을 유지하는 데 우선순위를 두십시오.
- 인쇄 또는 코스웨어 전달에 사용할 경우 대상 컴퓨터에서 글꼴, 바둑판 그림 및 페이징 효과를 확인해야 합니다. 호환성이 확실하지 않은 경우 데스크톱 버전을 PNG를 사용하여 내보낼 수 있습니다.
- KataGo 분석은 계속해서 CPU/GPU를 사용합니다. 노트 편집과 같은 가벼운 작업 중에는 분석을 중지하여 전력 소비와 장치 온도를 줄일 수 있습니다.
